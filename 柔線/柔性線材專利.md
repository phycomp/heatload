### 2. 片上多工技術
研究人員將經典電路與量子器件集成在同一晶片上，使用片上場效應電晶體（FET）對工作區網格進行多工處理，實現控制線數量近十倍的減少。該方法在 6×6 mm² 的陣列上成功運行，可在低溫環境和高磁場下操作。

### 4. 低溫微波控制介面
量子計算系統需要在毫開爾文（mK）溫度下運行的量子處理器與 4K 溫度下運行的電子介面之間建立高效連接。該介面涉及三個主要功能：多工/解多工、控制和讀取。為減少量子比特級（mK）與電子級（4K）之間的線纜數量，低溫多工器發揮關鍵作用。

## 摘要說明

這項專利涉及一種用於**低溫系統（cryogenic system）**中傳輸電磁信號的**柔性電纜（flexible cable）**，特別適用於**量子計算系統**。

### 核心技術特點

| 特徵 | 說明 |
|------|------|
| **結構** | 信號層（signal layer）+ 接地層（ground layer）層壓結構 |
| **信號線結構** | 多層結構（multilayer structure）：非超導材料層（如金、銅等貴金屬）+ 錸（Rhenium, Re）金屬層 |
| **超導特性** | 錸金屬具有**非晶態（amorphous）**結構，臨界溫度 Tc > 4K |
| **熱特性** | 低熱導率（low thermal conductivity），適合低溫環境 |
| **可焊性** | 表面可鍍金（Au），可用低熔點焊料（<150°C）連接 |
| **製程** | 電鍍（electroplating）製程，相容標準電路板材料 |
