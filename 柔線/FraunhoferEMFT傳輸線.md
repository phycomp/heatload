## Fraunhofer EMFT 低溫柔性傳輸線技術參數

### 核心技術特點

Fraunhofer EMFT 采用 **卷對卷 Roll-to-Roll** 工藝生產超導柔性電纜，該技術源自其多年的電子系統集成經驗。

| 參數類別 | 具體參數 | 說明 |
|---------|---------|------|
| **信號密度** | **>80 條/英寸** | 每英寸超過80條獨立屏蔽信號線，業界領先 |
| **電纜厚度** | **<100 μm** | 超薄設計，顯著降低空間占用 |
| **屏蔽方式** | 每通道獨立屏蔽 | 80+ individually shielded signal lines |
| **導體材料** | 超導材料（具體類型未公開） | 確保信號完整性，降低損耗 |
| **集成功能** | 濾波器/衰減器 | 可直接集成帶通/低通濾波器、衰減器 |
| **連接方案** | PCB 直接接觸 | 定制化接觸元件，優化低溫信號傳輸 |
| **熱負荷** | 極低 | 顯著降低低溫恒溫器的被動熱傳導 |

## 技術意義解讀

Fraunhofer EMFT 的技術對于**百比特級以上量子計算機**具有重要意義：

1. **突破布線瓶頸**：>80線/英寸的密度可大幅減少低溫恒溫器的穿板孔需求
2. **降低熱負荷**：超薄設計 + 超導材料 = 極低被動熱傳導，更高效利用有限制冷功率
3. **集成功能**：直接在電纜中集成濾波器，減少分立元件數量
4. **無長度限制**：卷對卷工藝可生產任意長度電纜，無需拼接

這與 Delft Circuits 的 Cri/oFlex 形成**互補競爭**——後者側重成熟產品化，前者追求極限密度和可擴展性。
