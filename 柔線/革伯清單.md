## 各層詳細規格

### 1. Signal Layer (CF3_SIG.gbr) - L4 中心導體層

```
Aperture 定義：
├─ D10: Circle, Ø220 μm → 訊號線寬
├─ D20: Rectangle, 2.5×2.0 mm → SMA 訊號焊盤
└─ D21: Rectangle, 3.0×2.0 mm → SMA 接地焊盤

8 通道座標（X 軸，單位：mm）：
CH1: X=1.00  │  CH2: X=3.00  │  CH3: X=5.00  │  CH4: X=7.00
CH5: X=9.00  │  CH6: X=11.00 │  CH7: X=13.00 │  CH8: X=15.00

Pitch: 2.00 mm（中心距）
Edge-to-edge spacing: 1.78 mm
```

### 2. Ground Planes (CF3_TOP_GND.gbr / CF3_BOT_GND.gbr) - L2/L6

```
結構：實心接地平面，全寬 16 mm 覆蓋
Via 開孔：Ø150 μm（鑽孔）/ Ø300 μm（焊盤）
開孔位置：與通道對齊，每 10 mm 交錯排列
```

### 3. Via Layer (CF3_VIA.gbr) - 接地盲孔

```
類型：Blind Via（L2↔L6）
鑽孔直徑：150 μm
排列：交錯式（Staggered）
  Row 1: Y=5mm,  X=1,3,5,7,9,11,13,15 mm
  Row 2: Y=10mm, X=3,5,7,9,11,13 mm（偏移 2mm）
  Row 3: Y=15mm, X=1,3,5,7,9,11,13,15 mm
Pitch: 10 mm（長度方向）/ 交錯 5 mm（寬度方向）
```

### 4. Coverlay (CF3_TOP_CVR.gbr) - L1 上覆蓋層

```
極性：Negative（負片）
開孔：
├─ Via 開孔：Ø200 μm（對齊 Via 位置）
└─ 連接器開孔：3.5×3.0 mm（對齊 SMA 焊盤）
```

### 5. Board Outline (CF3_EDGE.gbr)

```
外形：16 mm（寬）× 400 mm（長，可客製化 200-1000 mm）
圓角：1 mm 倒角（四個角落）
公差：±0.1 mm
```
