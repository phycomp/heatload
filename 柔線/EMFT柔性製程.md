## 一、Fraunhofer EMFT 超導傳輸線概覽

Fraunhofer EMFT（弗勞恩霍夫微電子與系統研究所）位於德國慕尼黑，是歐洲量子計算硬體研發的核心機構之一。其超導傳輸線技術主要服務於 **100+ 量子位元** 規模的超導量子電腦，採用 **Roll-to-Roll（R2R）卷對卷製程** 實現大規模生產 。


## 二、材質結構與設計

### 核心材料堆疊

Fraunhofer EMFT 的超導傳輸線採用 **多層屏蔽帶狀線（Shielded Stripline）** 結構 ：

```
┌─────────────────────────────────────┐
│  上屏蔽層（Top Shield）             │
│─────── 超導材料（Nb、NbTi 或 Al）───│
├─────────────────────────────────────┤
│  介電層（Dielectric）               │
│─────── Polyimide（聚醯亞胺）─────── │  < 100 μm 總厚度
├─────────────────────────────────────┤
│  中心導體（Center Conductor）       │
│────── 超導材料（Nb、NbTi 或 Al）────│
├─────────────────────────────────────┤
│  介電層（Dielectric）               │
│─────── Polyimide（聚醯亞胺）──────  │
├─────────────────────────────────────┤
│  下屏蔽層（Bottom Shield）          │
│────── 超導材料（Nb、NbTi 或 Al）────│
└─────────────────────────────────────┘
```

### 材料選擇與特性

| 材料 | 功能 | 關鍵特性 |
|------|------|---------|
| **Polyimide（聚醯亞胺）** | 柔性介電基板 | 耐溫 -269°C 至 400°C，低溫保持柔韌性，低微波損耗  |
| **Niobium (Nb)** | 超導導體/屏蔽層 | 臨界溫度 9.2 K，適合 4K 環境，CMOS 相容製程  |
| **Niobium-Titanium (NbTi)** | 超導導體 | 臨界溫度 ~9.5 K，機械強度高，適合柔性應用 |
| **Aluminum (Al)** | 超導導體/量子位元 | 臨界溫度 1.2 K，適合 mK 級量子位元，T1 可達 200 μs  |
| **Titanium Nitride (TiN)** | 替代超導材料 | 可調臨界溫度，用於 3D 整合與矽穿孔（TSV） |

### 與 Delft Cri/oFlex 的材質差異

| 特性 | Fraunhofer EMFT | Delft Cri/oFlex |
|------|----------------|----------------|
| **導體材料** | Nb、Al、TiN（超導為主） | Ag（標準）或 NbTi（超導版） |
| **介電材料** | Polyimide | Polyimide |
| **總厚度** | **< 100 μm**（更薄） | 300 μm  |
| **屏蔽結構** | 全屏蔽（上下屏蔽層） | 部分屏蔽（Stripline 結構） |

## 四、製程（Fabrication）詳解

Fraunhofer EMFT 的核心競爭力在於其 **工業級 Roll-to-Roll（R2R）卷對卷製程**，結合半導體微影技術與柔性電子製造 。

### 1. 基板準備（Substrate Preparation）

| 步驟 | 工藝細節 |
|------|---------|
| **材料選擇** | 商業化聚醯亞胺薄膜（如 DuPont Kapton®） |
| **厚度控制** | 總厚度 < 100 μm，由多層薄膜疊合 |
| **表面處理** | 電漿清潔（Plasma cleaning）提升金屬附著性 |
| **平整度控制** | R2R 製程確保薄膜張力均勻 |

### 2. 金屬化製程（Metallization）

根據官方文件與學術論文，Fraunhofer EMFT 採用以下沉積技術 ：

**對於鋁（Al）量子位元電路：**

- **沉積方法**：直流磁控濺鍍（DC magnetron sputtering）
- **厚度**：150 nm（電極層）
- **前處理**：HF 浸漬 3 分鐘 + N₂ 乾燥清潔
- **圖案化**：i-line 步進機光刻（365 nm）+ 氯基乾蝕刻

**對於鈮（Nb）與鈦氮化物（TiN）：**

- **沉積方法**：RF/DC 磁控濺鍍
- **沉積速率**：Nb 約 0.4 nm/s ；TiN 反應濺鍍（Ar:N₂ = 10:1）
- **厚度範圍**：10–300 nm（依功能需求）
- **壓力控制**：微調至微壓縮應力（slightly compressive stress）以避免剝離

### 3. Roll-to-Roll 微影製程（R2R Lithography）

這是 Fraunhofer EMFT 的關鍵創新，實現「無限長度」纜線生產 Roll-to-Roll 製程流程：

```
 聚醯亞胺薄膜卷軸
     ▼
    清潔區段    → 電漿清潔、除塵
     ▼
    金屬沉積區  → DC/RF 濺鍍（屏蔽層）
     ▼
    光刻區段    → 數位光刻（Digital Lithography）
                → 解析度可達 20 μm 線寬/線距
     ▼
    蝕刻區段    → 濕式化學蝕刻（Cu、Al）或乾蝕刻（Nb）
     ▼
    介電層疊合  → 第二層聚醯亞胺壓合
     ▼
   中心導體製作 → 重複金屬化+光刻+蝕刻
     ▼
   上層結構     → 介電層 + 上屏蔽層
     ▼
   雷射結構化   → 通孔（Via）鑽孔、外形切割
     ▼
   測試與分卷   → 電性測試、品質檢驗
     ▼
 成品卷軸（可達數公尺長度）
```

### 4. 關鍵製程技術

#### 數位光刻（Digital Lithography）

| 特性 | 說明 |
|------|------|
| **無掩模技術** | 直接以數位圖案曝光，無需光罩 |
| **拼接能力** | 可將 10 cm 線段圖案無縫拼接，實現任意長度  |
| **設計彈性** | 支援客製化幾何形狀，快速設計變更 |
| **線寬/線距** | 可達 **20 μm**  |

#### 雷射結構化（Laser Structuring）

| 應用 | 技術細節 |
|------|---------|
| **通孔鑽孔** | 雷射鑽孔連接上下屏蔽層 |
| **外形切割** | 精確切割纜線輪廓 |
| **微流道製作** | 亦可用於聚醯亞胺微結構  |

#### 濕式化學蝕刻（Wet Chemical Etching）

| 材料 | 蝕刻液 | 特性 |
|------|--------|------|
| **銅（Cu）** | 酸性蝕刻液（如 FeCl₃ 或 CuCl₂ 系） | 快速、選擇性高  |
| **鋁（Al）** | 氯基乾蝕刻或 TMAH 濕蝕刻 | 避免側蝕  |
| **鈮（Nb）** | 氟基乾蝕刻（CF₄/CHF₃） | 各向異性蝕刻  |
| **鉬（Mo）** | 磷酸基濕蝕刻 | 與光阻相容  |

## 七、總結

Fraunhofer EMFT 的超導傳輸線技術代表了 **歐洲量子計算基礎設施** 的重要發展方向，其核心優勢在於：

1. **工業級 R2R 製程**：結合半導體微影與卷對卷生產，實現可擴展性
2. **全超導設計**：採用 Al、Nb、TiN 等材料，確保 mK 級低損耗
3. **極高密度**：> 80 條屏蔽訊號線/英寸，支援 1000+ 量子位元
4. **系統整合能力**：從纜線、PCB 互連到 3D 晶片堆疊的完整解決方案

相較於 Delft Cri/oFlex，Fraunhofer EMFT 更強調 **製程可擴展性與未來量子電腦的擴展路線圖**，而 Delft 則在 **產品成熟度與市場可用性** 方面領先。兩者皆採用 Polyimide 作為介電材料，但在導體選擇與屏蔽設計上有所差異，反映了歐洲量子生態系中不同的技術路徑與應用定位。
