## 一、Cri/oFlex 系列材質結構

### 核心材料堆疊（Material Stack-up）

Cri/oFlex 採用 **Stripline（帶狀線）** 結構，其材料組成如下 ：

```
┌─────────────────────────────────────┐
│  Ground Plane（接地層）             │
│ ─────── Silver (Ag) 或 NbTi ─────── │  數微米厚
├─────────────────────────────────────┤
│  Dielectric（介電層）               │
│ ─────── Polyimide（聚醯亞胺）────── │  主要厚度
├─────────────────────────────────────┤
│ Center Conductor（中心導體）        │
│ ─────── Silver (Ag) 或 NbTi ─────── │  數微米厚
├─────────────────────────────────────┤
│  Dielectric（介電層）               │
│ ─────── Polyimide（聚醯亞胺）────── │
├─────────────────────────────────────┤
│ Ground Plane（接地層）              │
│ ─────── Silver (Ag) 或 NbTi ─────── │
└─────────────────────────────────────┘
      總厚度：0.3 mm（300 μm）
```

### 材料特性比較

| 材料 | 功能 | 特性 |
|--------|--------|----------------|
| **Polyimide（Kapton®）** | 柔性介電基板 | 耐溫範圍 -269°C 至 400°C，低溫下保持柔韌性  |
| **Silver (Ag)** | 導體材料（標準版） | 高導電性，但低溫下保持電阻性，熱導率高 |
| **Niobium-Titanium (NbTi)** | 導體材料（超導版） | 超導臨界溫度 ~9.2 K，微波損耗降低 50%，熱負載降低 10 倍  |

### 為何選擇 Polyimide？

根據 Delft Circuits 的技術說明，選擇 **Kapton®（聚醯亞胺）** 作為介電材料的原因 ：

1. **低溫柔韌性**：在極低溫（mK 級）環境下仍保持機械柔性，不會脆化
2. **熱穩定性**：可承受從室溫（300 K）到毫開爾文（10 mK）的熱循環
3. **微波性能**：適當的介電常數（εr ~3.4）和低損耗正切，適合高頻傳輸
4. **機械強度**：極薄的厚度（0.3 mm）下仍具備足夠的機械強度

## 二、工作操作環境

## 三、製程（Fabrication）詳解

雖然 Delft Circuits 未完全公開其專有製程細節，但根據官方文件、學術論文及類似柔性電路製程技術，可推論其製造流程如下：

### 1. 基板準備（Substrate Preparation）

| 步驟 | 說明 |
|------|------|
| **材料選擇** | 選用商業化聚醯亞胺薄膜（如 DuPont Kapton®） |
| **厚度控制** | 總厚度 0.3 mm，由多層薄膜疊合而成 |
| **清潔處理** | 化學清潔去除表面污染物，確保金屬附著性 |

### 2. 金屬化製程（Metallization）

根據學術文獻  和官方資訊，導體層的製造可能採用以下技術：

**對於 Ag（銀）版本：**

- **沉積方法**：電子束蒸鍍（E-beam evaporation）或濺鍍（Sputtering）
- **厚度**：數微米（μm）級別
- **圖案化**：光刻（Photolithography）+ 濕蝕刻或剝離（Lift-off）

**對於 NbTi（鈮鈦）超導版本：**

- **沉積方法**：直流磁控濺鍍（DC magnetron sputtering）
- **沉積速率**：約 0.4 nm/s 
- **厚度**：數微米，需精確控制以平衡微波損耗與熱負載 
- **圖案化**：雙層光阻剝離技術（Bilayer resist lift-off）

### 3. 多層結構疊合（Multilayer Lamination）

```
製程流程示意：

Step 1: 下接地層製作 Polyimide 薄膜 → Ag/NbTi 濺鍍 → 光刻圖案化 → 蝕刻形成 Ground Plane

Step 2: 介電層疊合 覆蓋第二層 Polyimide（介電層）→ 壓合（Lamination）

Step 3: 中心導體製作 Ag/NbTi 濺鍍 → 光刻定義中心導線圖案 → 蝕刻/剝離形成 Center Conductor

Step 4: 上介電層與接地層 覆蓋第三層 Polyimide → 壓合 → 上接地層金屬化 → 圖案化

Step 5: 通孔與連接 雷射鑽孔形成通孔（Via）→ 金屬化連接上下層
```

### 4. 整合元件製作（Integrated Components）

Cri/oFlex 3 的關鍵特色是將被動元件整合於柔性基板內 ：

**衰減器（Attenuator）：**

- 使用 **溫度穩定電阻膜**（TaN 或類似材料）
- 多個 5 dB 單元串聯設計
- 阻抗匹配網路確保 50 Ω

**低通濾波器（Low-Pass Filter）：**

- **階梯阻抗型（Stepped Impedance）** 設計
- 大面積金屬區域作為電容
- 細長導線段作為電感

**紅外線濾波器（IR Filter）：**

- 將 **懸浮金屬粉末** 嵌入介電層中
- 增加微波損耗以阻擋紅外線熱輻射

### 5. 微影製程細節（Photolithography Process）

參考類似柔性電路製程 ：

| 步驟 | 工藝參數 |
|------|---------|
| **光阻塗佈** | 乾膜光阻（Dry film photoresist）或液態光阻 |
| **曝光** | UV 曝光（365 nm），劑量約 1000 mJ/cm²  |
| **顯影** | PGMEA（Propylene Glycol Methyl Ether Acetate）顯影 |
| **蝕刻** | 濕蝕刻（Ag/NbTi 適用磷酸基蝕刻液） 或乾蝕刻 |
| **剝離** | 去除光阻，留下金屬圖案 |

### 6. 品質控制與測試

根據官方文件 ，Delft Circuits 在台夫特的無塵室進行：

- **室溫測試**：微波性能（S參數）、直流電阻
- **低溫測試**：在稀釋製冷機中測試 4K 與 mK 級性能
- **熱循環測試**：驗證機械可靠性

## 四、與其他柔性材質的比較

| 材質 | 優點 | 缺點 | 適用性 |
|---------|-------|------|----|
| **Polyimide（Cri/oFlex 使用）** | 耐高溫、低溫柔韌、低損耗 | 成本較高 | ⭐⭐⭐ 最佳 |
| **PTFE（Teflon）** | 低介電常數、低損耗 | 低溫下易冷流變形 | ⭐⭐ 中等 |
| **PFA（氟塑膠）** | 化學穩定性高 | 低溫脆化、較厚 | ⭐⭐ 中等 |
| **LCP（液晶聚合物）** | 低吸濕性 | 低溫脆性、成本高 | ⭐⭐ 中等 |
| **PDMS（矽膠）** | 極柔軟、生物相容 | 高損耗、不耐高溫 | ⭐ 不適合微波 |

## 五、製程創新與挑戰

### Delft Circuits 的製程優勢

1. **無粘合劑多層結構（Adhesiveless）**：
   - 避免傳統丙烯酸粘合劑在低溫下的收縮與脫層問題 
   - 直接將金屬濺鍍於聚醯亞胺表面

2. **超薄化技術**：
   - 0.3 mm 厚度實現 8 通道高密度整合
   - 未來路線圖朝向 32 通道/條 

3. **超導材料整合**：
   - 將 NbTi 超導薄膜製程與柔性基板結合
   - 維持超導特性的同時保持機械柔性

### 製程挑戰

| 挑戰 | 解決方案 |
|----|----------|
| **金屬與聚醯亞胺附著性** | 表面電漿處理（Plasma treatment）增加表面能 |
| **熱膨脹係數不匹配** | 選擇匹配的薄膜厚度比例，避免彎曲應力 |
| **超導薄膜均勻性** | 大面積濺鍍系統，精確控制氣氛與溫度 |
| **精細圖案解析度** | 使用先進光刻設備（DUV 或雷射直寫）|

## 六、總結

Delft Cri/oFlex 系列的製程核心在於將 **半導體微影製程** 與 **柔性電路技術** 結合，創造出能在極低溫環境下運作的高密度微波傳輸線。其關鍵創新包括：

1. **材料選擇**：Polyimide + Ag/NbTi 的組合兼顧柔性、熱穩定性與微波性能
2. **Stripline 結構**：優於 Microstrip 的屏蔽特性，降低串擾
3. **整合製程**：將濾波器、衰減器等被動元件嵌入柔性基板，減少接點
4. **無塵室量產**：Delft Circuits 擁有 1000 m² 試產設施及新建 750 m² 無塵室 ，是目前唯一能大規模生產超導柔性電路的工業供應商

這種製程技術代表了量子計算基礎設施的重要突破，解決了傳統同軸電纜在規模化時的物理限制。
