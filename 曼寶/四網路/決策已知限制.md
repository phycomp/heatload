## 設計決策與已知限制（重要）

1. **模型選擇**：反推驗證發現你的參考計算機使用 IPC-2221 閉式解 + `εeff = 0.475εr + 0.67` + 銅電阻率 1.72e-8 Ω·m，因此後端預設 `method="ipc"` 以完全對齊黃金標準；Hammerstad/Jensen 作為替代模型可切換（兩者線寬結果差異約 5–10%，Hammerstad 物理上更嚴謹）。
2. **π 網路**：採 Q1 參數化解（已數值驗證 Zin = rs 精確成立），rs > rl 時 q1 有合法範圍上限，超出會拋出具體錯誤訊息。
3. **T 網路**：一般解的元件正負號依阻抗比而定，某些組合會得到混合拓撲（如串 C / 並 L），前端以 `zin_check` 呈現驗證結果。
4. **Stripline / CPWG / 差分對**為閉式近似（IPC-2221、保角映射、IPC-2141 經驗式），未經 EM 模擬驗證，建議高頻 (>5 GHz) 工作以 2.5D 求解器複核。
5. **NLU**：regex 層覆蓋中英常見句型，解析失敗時設有 LLM 兜底介面（以 `NLU_LLM_BASE/NLU_LLM_KEY` 環境變數配置 OpenAI 相容端點），但例句測試尚未在本環境執行過，上線前請先跑 `pytest tests/test_nlu` 部分確認。

整體架構：Streamlit 前端 → FastAPI（`/api/parse` 混合 NLU、`/api/design/*` 四種傳輸線、`/api/match/*` 四種匹配網路）→ 已驗證的計算核心。
