## 🔬 傳輸矩陣嚴格推導與Berry相位數值穩定算法

### 一、傳輸矩陣的嚴格電磁場推導

#### 1. 從Maxwell方程到傳輸矩陣

**起始方程**（時諧場 $e^{-i\omega t}$）：
$$
\nabla \times \mathbf{E} = i\omega\mu_0 \mathbf{H} \\
\nabla \times \mathbf{H} = -i\omega\epsilon_0 \epsilon(\omega, \mathbf{k}) \mathbf{E}
$$

**分層結構假設**：
- 薄膜法向沿 $z$ 軸
- 平面波在 $xy$ 平面傳播：$\mathbf{k} = (k_x, k_y, k_z)$
- 各層介電函數：$\epsilon_j(\omega)$

---

#### 2. 邊界條件的嚴格匹配

**切向場連續**（在 $z=z_j$ 界面）：
$$
\mathbf{E}_{t}^{(j)} = \mathbf{E}_{t}^{(j+1)} \\
\mathbf{H}_{t}^{(j)} = \mathbf{H}_{t}^{(j+1)}
$$

**TM波（磁場沿y方向）**：
$$
E_x = \frac{1}{\epsilon} \frac{\partial H_y}{\partial z}, \quad 
E_z = -\frac{i k_x}{\epsilon} H_y \\
\frac{\partial H_y}{\partial z} = i\omega\epsilon_0 \epsilon E_x
$$

**場表示形式**：
在第 $j$ 層中：
$$
H_y^{(j)}(z) = A_j e^{i k_{zj} (z-z_j)} + B_j e^{-i k_{zj} (z-z_j)}
$$

---

#### 3. 傳輸矩陣的解析推導

**界面矩陣**（$z_j$ 處）：
$$
\begin{pmatrix}
H_y^{(j)} \\
\frac{1}{\epsilon_j} \frac{\partial H_y^{(j)}}{\partial z}
\end{pmatrix}
=
\mathbf{M}_{j,j+1}
\begin{pmatrix}
H_y^{(j+1)} \\
\frac{1}{\epsilon_{j+1}} \frac{\partial H_y^{(j+1)}}{\partial z}
\end{pmatrix}
$$

**求解系數矩陣**：
$$
\mathbf{M}_{j,j+1} = \frac{1}{2}
\begin{pmatrix}
1 + \eta_{j,j+1} & 1 - \eta_{j,j+1} \\
1 - \eta_{j,j+1} & 1 + \eta_{j,j+1}
\end{pmatrix}
$$

其中阻抗比：
$$
\eta_{j,j+1} = \frac{k_{zj} \epsilon_{j+1}}{k_{z,j+1} \epsilon_j}
$$

**傳播矩陣**（在層 $j$ 內，厚度 $d_j$）：
$$
\mathbf{P}_j(d_j) = 
\begin{pmatrix}
e^{i k_{zj} d_j} & 0 \\
0 & e^{-i k_{zj} d_j}
\end{pmatrix}
$$

**總傳輸矩陣**（遞歸關系）：
$$
\mathbf{M}_{\text{total}} = \mathbf{M}_{0,1} \mathbf{P}_1(d_1) \mathbf{M}_{1,2} \mathbf{P}_2(d_2) \cdots \mathbf{M}_{N-1,N}
$$

```python
import numpy as np
from scipy.linalg import expm
from typing import Tuple, List

class RigorousTransferMatrix:
    """數值穩定的傳輸矩陣求解器"""
    
    def __init__(self, wavelengths: np.ndarray, 
                 epsilon_func: callable,
                 thicknesses: List[float]):
        """
        Args:
            wavelengths: 波長範圍 (m)
            epsilon_func: 介電函數 ε(ω, z)
            thicknesses: 各層厚度 (m)
        """
        self.omega = 2*np.pi * PHYSICAL_CONSTANTS['c'] / wavelengths
        self.epsilon_func = epsilon_func
        self.thicknesses = thicknesses
        self.num_layers = len(thicknesses)
        
    def solve_field_distribution(self, incident_angle: float, 
                                 polarization: str = 'TM') -> Dict:
        """
        嚴格求解場分布（處理倏逝波穩定性問題）
        """
        # 波矢分量
        k0 = self.omega / PHYSICAL_CONSTANTS['c']
        kx = k0 * np.sin(incident_angle)
        
        # 各層法向波矢
        kz = []
        for j in range(self.num_layers):
            eps_j = self.epsilon_func(self.omega, np.sum(self.thicknesses[:j]))
            kz_j = np.sqrt(k0**2 * eps_j - kx**2 + 0j)  # 0j強制復數
            kz.append(kz_j)
        
        # 數值穩定化：重新標度處理大指數
        M_total = self._stabilized_matrix_recursion(kx, kz)
        
        # 提取反射/透射系數
        r = M_total[1,0] / M_total[0,0]
        t = 1.0 / M_total[0,0]
        
        # 場分布計算
        field_z = self._calculate_field_profile(kx, kz, M_total)
        
        return {
            'reflectance': np.abs(r)**2,
            'transmittance': np.abs(t)**2,
            'field_profile': field_z,
            'total_matrix': M_total
        }
    
    def _stabilized_matrix_recursion(self, kx: float, 
                                     kz: List[complex]) -> np.ndarray:
        """
        數值穩定的遞歸算法（S-矩陣方法變體）
        避免指數爆炸：ē^{±ikd} → ē^{±ikd/2} ... ē^{±ikd/2}
        """
        # 初始化單位矩陣
        S = np.eye(2, dtype=complex)
        
        # 底層（真空）
        eps_sub = self.epsilon_func(self.omega, 0)
        eta_last = kz[-1] / (self.omega/PHYSICAL_CONSTANTS['c'] * np.sqrt(eps_sub))
        
        # 逆向遞歸（從襯底開始）
        for j in range(self.num_layers-1, -1, -1):
            # 傳播因子半層分解
            phase_half = 1j * kz[j] * self.thicknesses[j] / 2
            
            # 數值穩定化：對大乘數進行對數處理
            if np.imag(phase_half) > 10:  # 強衰減
                exp_term = np.exp(phase_half)
                # 使用對數域計算
                log_S = self._log_matrix(S)
                log_update = np.array([[phase_half, 0], [0, -phase_half]])
                S = expm(log_S + log_update)
            else:
                P_half = np.array([[np.exp(phase_half), 0],
                                 [0, np.exp(-phase_half)]], dtype=complex)
                S = P_half @ S @ P_half
            
            # 界面矩陣（如果j>0）
            if j > 0:
                eps_current = self.epsilon_func(self.omega, np.sum(self.thicknesses[:j]))
                eps_prev = self.epsilon_func(self.omega, np.sum(self.thicknesses[:j-1]))
                
                eta = (kz[j-1] * eps_current) / (kz[j] * eps_prev)
                
                M_interface = 0.5 * np.array([
                    [1 + eta, 1 - eta],
                    [1 - eta, 1 + eta]
                ], dtype=complex)
                
                S = M_interface @ S
        
        return S
    
    def _log_matrix(self, M: np.ndarray, max_term: int = 10) -> np.ndarray:
        """矩陣對數（級數展開）"""
        I = np.eye(M.shape[0])
        R = M - I
        
        logM = np.zeros_like(M)
        sign = 1
        for n in range(1, max_term):
            logM += sign * np.linalg.matrix_power(R, n) / n
            sign *= -1
        
        return logM
    
    def _calculate_field_profile(self, kx: float, kz: List[complex],
                                 M_total: np.ndarray) -> np.ndarray:
        """計算歸一化場分布"""
        z_points = np.linspace(0, sum(self.thicknesses), 200)
        H_field = np.zeros(len(z_points), dtype=complex)
        
        A_incident = 1.0
        B_reflected = M_total[1,0] / M_total[0,0] * A_incident
        
        for i, z in enumerate(z_points):
            # 確定所在層
            layer_idx = self._find_layer(z)
            
            # 層內坐標
            z_local = z - sum(self.thicknesses[:layer_idx])
            
            # 前向/反向波振幅
            if layer_idx == 0:
                A = A_incident
                B = B_reflected
            else:
                # 從傳輸矩陣提取
                A = M_total[0,0] * A_incident
                B = M_total[0,1] * A_incident
            
            kz_j = kz[layer_idx]
            H_field[i] = A * np.exp(1j * kz_j * z_local) + \
                         B * np.exp(-1j * kz_j * z_local)
        
        return np.abs(H_field)**2
    
    def _find_layer(self, z: float) -> int:
        """查找位置所在層"""
        cum_thickness = np.cumsum([0] + self.thicknesses)
        for idx, (z_start, z_end) in enumerate(zip(cum_thickness[:-1], cum_thickness[1:])):
            if z_start <= z <= z_end:
                return idx
        return self.num_layers - 1
```

### 二、Berry相位數值穩定算法

#### 1. 理論基礎：離散化公式

**Berry聯絡**：
$$
\mathbf{A}_n(\mathbf{k}) = i\langle u_n(\mathbf{k}) | \nabla_{\mathbf{k}} | u_n(\mathbf{k}) \rangle
$$

**離散化（Fukui方法）**：
$$
\Omega(\mathbf{k}) = \text{Im} \ln \prod_{i=1}^{4} 
\langle u_n(\mathbf{k}_i) | u_n(\mathbf{k}_{i+1}) \rangle
$$

其中 $\mathbf{k}_1 \to \mathbf{k}_2 \to \mathbf{k}_3 \to \mathbf{k}_4 \to \mathbf{k}_1$ 圍繞布裏淵區微元。

---

#### 2. 數值穩定性問題與解決方案

**問題1：相位纏繞（Branch Cut）**
- **現象**：重叠積分的復對數在 $-\pi/\pi$ 處不連續
- **解決方案**：**規範固定**，強制第一分量爲實正數

```python
def gauge_fix(wavefunction: np.ndarray) -> np.ndarray:
    """規範固定：使第一分量爲正實數"""
    phase = np.angle(wavefunction[0])
    return wavefunction * np.exp(-1j * phase)
```

**問題2：簡并點奇異性**
- **現象**：在狄拉克點，波函數不可定義
- **解決方案**：**自適應網格加密 + 簡并子空間投影**

```python
def project_degenerate_subspace(kx: float, ky: float, 
                               eigenvectors: np.ndarray, 
                               eigenvalues: np.ndarray,
                               degeneracy_threshold: float = 1e-6) -> np.ndarray:
    """
    簡并子空間投影
    檢測能量簡并，構建正交化基矢
    """
    # 尋找簡并簇
    energy_diff = np.abs(eigenvalues[:, np.newaxis] - eigenvalues[np.newaxis, :])
    degenerate_pairs = np.argwhere(energy_diff < degeneracy_threshold)
    
    if len(degenerate_pairs) > 0:
        # SVD正交化
        U, S, Vh = np.linalg.svd(eigenvectors, full_matrices=False)
        return U[:, :len(eigenvalues)]
    
    return eigenvectors
```

**問題3：累積數值誤差**
- **現象**：長網格路徑上相位誤差累積
- **解決方案**：**并行區域分解 + 高精度重叠積分**

#### 3. 最優離散化算法實現

```python
import numpy as np
from scipy.linalg import svd, qr
from typing import Tuple, Optional
import warnings

class StableBerryPhaseCalculator:
    """數值穩定的Berry相位計算"""
    
    def __init__(self, hamiltonian_func: callable, 
                 mesh_size: Tuple[int, int] = (50, 50),
                 gauge: str = 'Parallel'):
        """
        Args:
            hamiltonian_func: H(kx, ky) 函數
            mesh_size: k網格大小
            gauge: 規範選擇 ('Parallel', 'Fixed')
        """
        self.H = hamiltonian_func
        self.nx, self.ny = mesh_size
        self.gauge = gauge
        
        # 預計算k網格
        self.kx_grid = np.linspace(-0.5, 0.5, self.nx)
        self.ky_grid = np.linspace(-0.5, 0.5, self.ny)
        
        # 存儲特征向量（用于緩存）
        self._eigenvector_cache = {}
        
    def compute_chern_number(self, band_index: int = 0) -> Tuple[float, np.ndarray]:
        """
        計算Chern數（穩定實現）
        返回：Chern數, Berry曲率分布
        """
        berry_curvature = np.zeros((self.nx-1, self.ny-1))
        
        # 使用四格點法計算每個網格Berry曲率
        for i in range(self.nx - 1):
            for j in range(self.ny - 1):
                # 四頂點
                k_vertices = [
                    (self.kx_grid[i], self.ky_grid[j]),
                    (self.kx_grid[i+1], self.ky_grid[j]),
                    (self.kx_grid[i+1], self.ky_grid[j+1]),
                    (self.kx_grid[i], self.ky_grid[j+1]),
                ]
                
                # 穩定化計算
                berry_curvature[i, j] = self._compute_plaquette_phase(
                    k_vertices, band_index, method='Wilson_loop'
                )
        
        # 積分
        chern = np.sum(berry_curvature) / (2 * np.pi)
        
        return chern, berry_curvature
    
    def _compute_plaquette_phase(self, k_vertices: List[Tuple[float, float]], 
                                 band: int,
                                 method: str = 'Wilson_loop') -> float:
        """
        單格點Berry曲率計算（Wilson Loop方法）
        數值最穩定的實現
        """
        if method == 'Wilson_loop':
            return self._wilson_loop_phase(k_vertices, band)
        else:
            return self._finite_difference_phase(k_vertices, band)
    
    def _wilson_loop_phase(self, k_vertices: List[Tuple[float, float]], 
                           band: int) -> float:
        """
        Wilson Loop相位計算
        最優數值穩定性：U(1)鏈式乘積
        """
        # 獲取各點波函數
        psi = [self._get_eigenfunction(k[0], k[1], band) for k in k_vertices]
        
        # 規範固定
        if self.gauge == 'Fixed':
            psi = [self._apply_gauge_fix(p) for p in psi]
        elif self.gauge == 'Parallel':
            psi = self._parallel_transport_gauge(psi)
        
        # 重叠積分鏈
        overlap_product = 1.0 + 0j
        
        for i in range(4):
            # 相鄰點重叠積分
            overlap = self._stable_overlap(psi[i], psi[(i+1)%4])
            
            # 數值穩定化：限制模長
            overlap = overlap / np.abs(overlap)  # 歸一化到單位圓
            overlap_product *= overlap
        
        # 相位提取
        phase = np.angle(overlap_product)
        
        # 保證相位在 [-π, π]
        return (phase + np.pi) % (2 * np.pi) - np.pi
    
    def _get_eigenfunction(self, kx: float, ky: float, band: int) -> np.ndarray:
        """帶緩存的特征向量計算"""
        key = (round(kx, 6), round(ky, 6), band)
        
        if key not in self._eigenvector_cache:
            H = self.H(kx, ky)
            eigenvals, eigenvecs = np.linalg.eigh(H)
            
            # 簡并檢測與處理
            eigenvecs = self._handle_degeneracies(H, eigenvals, eigenvecs)
            
            self._eigenvector_cache[key] = eigenvecs[:, band]
        
        return self._eigenvector_cache[key].copy()
    
    def _handle_degeneracies(self, H: np.ndarray, 
                             eigenvals: np.ndarray, 
                             eigenvecs: np.ndarray,
                             threshold: float = 1e-8) -> np.ndarray:
        """
        簡并子空間處理（關鍵穩定性步驟）
        使用Gram-Schmidt正交化
        """
        # 檢測簡并簇
        n_bands = len(eigenvals)
        processed = np.zeros(n_bands, dtype=bool)
        result_vecs = eigenvecs.copy()
        
        for i in range(n_bands):
            if processed[i]:
                continue
            
            # 找到簡并伙伴
            degenerate_idx = np.where(np.abs(eigenvals - eigenvals[i]) < threshold)[0]
            
            if len(degenerate_idx) > 1:
                # 子空間正交化
                subspace = eigenvecs[:, degenerate_idx]
                Q, R = qr(subspace, mode='economic')
                
                # 相位對齊
                for j, idx in enumerate(degenerate_idx):
                    result_vecs[:, idx] = Q[:, j]
                    processed[idx] = True
            else:
                processed[i] = True
        
        return result_vecs
    
    def _apply_gauge_fix(self, psi: np.ndarray) -> np.ndarray:
        """規範固定：第一分量正實部"""
        max_idx = np.argmax(np.abs(psi))
        phase = np.angle(psi[max_idx])
        return psi * np.exp(-1j * phase)
    
    def _parallel_transport_gauge(self, psi_chain: List[np.ndarray]) -> List[np.ndarray]:
        """
        平行輸運規範（最優連續性）
        使相鄰點波函數變化最小
        """
        gauged = [psi_chain[0]]
        
        for i in range(1, len(psi_chain)):
            overlap = np.vdot(gauged[-1], psi_chain[i])
            phase = np.angle(overlap)
            gauged.append(psi_chain[i] * np.exp(-1j * phase))
        
        return gauged
    
    def _stable_overlap(self, psi1: np.ndarray, psi2: np.ndarray) -> complex:
        """
        數值穩定的重叠積分
        避免下溢/上溢
        """
        # 分塊計算
        overlap = np.vdot(psi1, psi2)
        
        # 模長限制
        abs_overlap = np.abs(overlap)
        if abs_overlap < 1e-16:
            warnings.warn("極小的重叠積分，可能數值不穩定")
            return 1e-16 + 0j
        
        return overlap
    
    def compute_z2_invariant(self) -> int:
        """
        Z2不變量計算（Fu-Kane方法）
        時間反演不變點(TRIM)計算
        """
        # TRIM點
        trim_points = np.array([
            [0.0, 0.0],
            [0.5, 0.0],
            [0.0, 0.5],
            [0.5, 0.5]
        ])
        
        # 在每個TRIM點計算占據態宇稱
        parity_product = 1
        
        for kx, ky in trim_points:
            H = self.H(kx, ky)
            eigenvals, eigenvecs = np.linalg.eigh(H)
            
            # 占據態（能量<0）
            occupied = eigenvecs[:, :2]  # 兩個占據帶
            
            # 時間反演算符 T = iσ_y K
            sigma_y = np.array([[0, -1j], [1j, 0]], dtype=complex)
            T = np.kron(sigma_y, np.eye(2))  # 4x4矩陣
            
            # 計算宇稱本征值
            for n in range(2):
                psi_n = occupied[:, n]
                TR_psi = T @ np.conj(psi_n)
                
                # 檢查Kramers對
                overlap = np.dot(psi_n.conj(), TR_psi)
                if np.abs(overlap) > 0.9:  # Kramers簡并
                    parity = np.sign(np.imag(overlap))
                    parity_product *= parity
        
        return (-1j * np.log(parity_product + 0j) / np.pi) % 2
    
    def compute_berry_connection(self, band: int) -> Tuple[np.ndarray, np.ndarray]:
        """
        Berry聯絡 A(k) = <ψ|∇_k|ψ>
        用于可視化
        """
        Ax = np.zeros((self.nx, self.ny), dtype=complex)
        Ay = np.zeros((self.nx, self.ny), dtype=complex)
        
        dk_x = self.kx_grid[1] - self.kx_grid[0]
        dk_y = self.ky_grid[1] - self.ky_grid[0]
        
        for i, kx in enumerate(self.kx_grid):
            for j, ky in enumerate(self.ky_grid):
                # 中心差分（高精度）
                psi = self._get_eigenfunction(kx, ky, band)
                
                # x方向導數
                psi_x_forward = self._get_eigenfunction(kx + dk_x, ky, band)
                psi_x_backward = self._get_eigenfunction(kx - dk_x, ky, band)
                dpsi_dx = (psi_x_forward - psi_x_backward) / (2 * dk_x)
                
                # y方向導數
                psi_y_forward = self._get_eigenfunction(kx, ky + dk_y, band)
                psi_y_backward = self._get_eigenfunction(kx, ky - dk_y, band)
                dpsi_dy = (psi_y_forward - psi_y_backward) / (2 * dk_y)
                
                Ax[i,j] = 1j * np.vdot(psi, dpsi_dx)
                Ay[i,j] = 1j * np.vdot(psi, dpsi_dy)
        
        return Ax, Ay

def example_berry_calculation():
    """Berry相位計算示例"""
    # 定義哈密頓量函數
    def haldane_hamiltonian(kx: float, ky: float, 
                            M: float = 0.5, t2: float = 0.1):
        """Haldane模型（Chern絕緣體）"""
        sigma_x = np.array([[0,1],[1,0]], dtype=complex)
        sigma_y = np.array([[0,-1j],[1j,0]], dtype=complex)
        sigma_z = np.array([[1,0],[0,-1]], dtype=complex)
        
        # 最近鄰躍遷
        d_x = np.cos(kx) + np.cos(ky/2) * np.cos(np.sqrt(3)*ky/2)
        d_y = np.sin(kx) - np.sin(ky/2) * np.cos(np.sqrt(3)*ky/2)
        d_z = M + 2 * t2 * np.sin(kx) * np.sin(ky/2) * np.sin(np.sqrt(3)*ky/2)
        
        return d_x * sigma_x + d_y * sigma_y + d_z * sigma_z
    
    # 初始化計算器
    berry_calc = StableBerryPhaseCalculator(
        hamiltonian_func=lambda kx, ky: haldane_hamiltonian(kx, ky, M=1.0),
        mesh_size=(80, 80),
        gauge='Parallel'
    )
    
    # 計算Chern數
    chern, curvature = berry_calc.compute_chern_number(band_index=0)
    
    print(f"Chern數: {chern:.6f}")  # 應接近1
    
    # 可視化Berry曲率
    import matplotlib.pyplot as plt
    
    plt.imshow(np.real(curvature), cmap='RdBu',
               extent=[-0.5, 0.5, -0.5, 0.5])
    plt.colorbar(label='Berry曲率')
    plt.title(f'Chern數 = {chern:.3f}')
    plt.xlabel('kx')
    plt.ylabel('ky')
    plt.savefig('berry_curvature.png', dpi=300)
    plt.close()
```

### 三、數值穩定性參數建議

#### 傳輸矩陣穩定性
| 問題類型 | 判據條件 | 解決方案 | 參數設置 |
|---------|---------|---------|---------|
| **指數溢出** | $\Im(k_z d) > 20$ | 對數域計算 | `max_imag_phase = 15` |
| **相消誤差** | $|1 - \eta| < 1e-8$ | 泰勒展開 | `eta_regularization = 1e-6` |
| **矩陣病態** | `cond(M) > 1e12` | SVD正則化 | `rcond_threshold = 1e-10` |

#### Berry相位穩定性
| 問題類型 | 判據條件 | 解決方案 | 參數設置 |
|---------|---------|---------|---------|
| **規範奇點** | $|\psi_0| < 1e-10$ | 最大分量固定 | `gauge_fix_threshold = 1e-8` |
| **簡并災難** | $\Delta E < 1e-6$ | 子空間QR分解 | `degeneracy_cutoff = 1e-6` |
| **相位纏繞** | $|\Delta\phi| > \pi$ | 并行輸運 | `transport_step = 0.05` |
