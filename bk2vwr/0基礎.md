### A. 物理意義速記

| 名詞 | 英文 | 物理意義（一句話版本） | 與 S 參數關係 | 數值越… 越好 |
|----|------|----------------------|--------------|-------------|
| 回波損耗 | Return Loss, RL | 「打回來」的能量愈少愈好 → 代表阻抗銜接順暢 | RL = ‑20 log₁₀|S₁₁| (dB) | 越大（如 ‑30 dB）越好 |
| 插入損耗 | Insertion Loss, IL | 「送到下游」的能量衰減愈小愈好 → 代表線本身很乾淨 | IL = ‑20 log₁₀|S₂₁| (dB) | 越小（如 ‑1 dB）越好 |
| S₁₁ | 反射係數 | Port-1 的反射波／入射波 | 直接就是 Γ (反射係數) | 越接近 0（線性值）越好 |
| S₂₁ | 透射係數 | Port-1→Port-2 的透射波／入射波 | 直接決定 IL | 越接近 1（0 dB）越好 |
| S₂₂、S₁₂ | 反向版本 | S₂₂ 是從 Port-2 看回去的反射；S₁₂ 是 Port-2→Port-1 的透射 | 互易線路 S₁₂=S₂₁ | 同 S₁₁、S₂₁ 的期待值 |

**頻域 vs. 時域的直覺連結**  
- 頻域：一次把所有正弦穩態掃出來 → 馬上看到「哪些頻率被吃掉」（IL 大）或「哪些頻率愛反彈」（RL 大）。  
- 時域：把 S 參數做 IFFT 得到脈衝響應 → 可直接量「走 10 cm 線，脈衝變多胖、多高、尾巴多久」，一眼看出符號間干擾 (ISI) 嚴重程度。  
兩者互補：頻域找共振點，時域看眼團不團。

### B. Streamlit 互動範例

下面程式碼讓你上傳一份 Touchstone (.s2p) 或直接在滑桿調「理想線」的長度、損耗，左邊畫頻域 S₁₁ / S₂₁，右邊畫時域脈衝響應（|S₂₁|² 的 IFFT 再包絡檢波）。貼到 `app.py` 後 `streamlit run app.py` 即可。

### 如何使用這段程式學物理

1. 先玩「理想模型」：  
   - 把衰減常數調大 → 頻域 S₂₁ 整條往下掉（IL 變差），時域脈衝高度變矮（能量真的被吃掉了）。  
   - 把線長拉長 → 相位斜率變陡（S₂₁ 螺旋多轉幾圈），時域脈衝延遲增加，直觀看到「走線 delay」。  
   - 改 Z₀ → S₁₁ 大小變化，馬上看到阻抗不匹配時「反射」變大，時域也可能出現二次小脈衝（反射波回到源端再彈回來）。

2. 再載入實測 .s2p：  
   - 可能出現「某一頻率 S₁₁ 突然翹起」→ 代表該頻率有共振或連接器阻抗不連續；  
   - 時域會看到主脈衝後面多了一包「回音」→ 就是該反射事件在時間軸的位置。

### 小結

- RL / S₁₁ 告訴你「有多少波被彈回來」；IL / S₂₁ 告訴你「有多少波成功送到下游」。  
- 頻域一張圖就能掃出「全頻段體檢報告」；時域則把「每個不連續點」揪出來並給它時間戳記。  
- 用 Streamlit 把兩張圖並排，一邊調參數一邊看反應，比單純背公式更能感受「傳輸線長怎樣、訊號就長怎樣」。
