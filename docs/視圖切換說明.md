# 視圖切換 API 說明（量傳線核心）

## 函式

- `切換視圖(佈局, view, conductor_color=None, dielectric_color=None)`
  - view: "前"/"側"/"上" 或 "front"/"side"/"top" 或中文全名
- `繪製全部視圖(佈局, conductor_color=None, dielectric_color=None)` -> dict

## 使用範例

```python
import sys
sys.path.insert(0, "src")
from 量傳線設計.核心.三視圖 import LayoutCalculator, 切換視圖, 繪製全部視圖

佈局 = LayoutCalculator(通道數=8)
fig = 切換視圖(佈局, "側", conductor_color="#FF00FF")
d = 繪製全部視圖(佈局, conductor_color="#00FF00", dielectric_color="#0000FF")
```

## 顏色參數

`繪製前視` / `繪製側視` / `繪製上視` 皆支援 `conductor_color` 與 `dielectric_color`（預設 gold/copper）。
