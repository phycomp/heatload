# 文字轉換工具使用說明

## 檔案
`/home/sam/量傳線/文字轉換.py`

## 功能
將純文字檔 (.txt) 轉換為 Markdown，再轉換為 pptx 與 pdf。

## 使用方式

```bash
cd /home/sam/量傳線
python 文字轉換.py input.txt --title "標題" [--out-dir DIR]
```

## 輸出
- `input.md`：整理後的 Markdown
- `input.pptx`：PowerPoint
- `input.pdf`：PDF（透過 LibreOffice，支援中文）

## Markdown 整理規則（啟發式）
- 第一個非空行作為 H1 標題（若未指定 --title）
- 空行分段
- `- `/`* `/`• ` 開頭轉為項目符號
- 短行（<40 字且無結尾標點）轉為 H2

## 依賴
- pandoc（pptx）
- libreoffice（pdf）
