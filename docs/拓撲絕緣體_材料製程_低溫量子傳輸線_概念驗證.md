## 1. 概念定義與待驗證命題

### 1.1 概念定義（候選）
> **TI 低溫量子傳輸線概念**：利用三維強拓撲絕緣體（如 Bi₂Se₃ 家族）之受時間反演對稱保護的表面 Dirac 態作為低溫（~4 mK–10 K）微波/直流互連的導電通道（或與超導體形成混合互連），透過自旋-動量鎖定與背散射抑制降低耗散/串擾，並以薄膜製程（MBE/濺鍍/微影/鈍化/接觸）整合至共面波導（CPW）或柔性/帶狀互連結構。

### 1.2 待驗證命題
- **P1（物理機制）**：TI 表面態在 mK–K 溫區具拓撲保護與低體電導條件時，可提供相對有利的相干/低耗散傳輸通道（條件成立時）。
- **P2（材料與製程）**：Bi₂Se₃ 等 TI 可藉 MBE/濺鍍在介電基板上成長薄膜並以微影/鈍化/電極製程形成元件，但氧化、缺陷摻雜與接觸是決定性良率/性能因子。
- **P3（低溫量子傳輸線整合）**：TI 可作為低溫互連/量子電路元件之**前瞻性**候選（如 TIRC/CPW、TI Josephson 混合元件），但相較成熟 NbTi/Ag 柔性低溫傳輸線（CF3/crioFlex 類）仍處探索/原型階段，尚非通用商用替代。

## 2. 本機蒐證與物理模型觀念（Local Distill）

### 2.1 TI 材料系統與關鍵物性 `[本機來源]`
- 來源：`.opencode/skills/topological-insulator/references/02_材料系統.md`、`/home/sam/物理模擬/topo/distill/04_三維TI與材料篩選.md`、`distill/00_索引.md`。
- **第一代 3D TI（Bi₂Se₃ 家族）**：Bi₂Se₃（體隙 ~0.3 eV）、Bi₂Te₃（~0.15 eV）、Sb₂Te₃（~0.3 eV）；典型問題為本征缺陷導致體導電（Se 空位→n 型、Te 反位等），可短路表面態。
- **磁性 TI**：MnBi₂Te₄ 家族（T_N≈24–25 K 等），具本征磁性/axion/QAHE 候選潛力，但多在低溫與精密調控條件下觀測；與本命題（互連/傳輸線）關聯較間接（多屬元件/態調控），列為擴展背景。
- **工程核心問題—氧化/鈍化**：Bi₂Se₃ 表面暴露空氣可形成氧化層、降解表面態電導；本機策略為 MBE 後原位 Se 帽層、ALD Al₂O₃ 封裝、手套箱/真空傳輸（與 Stanford/Cui group 路線一致之本機摘要）。
- **選料準則（本機弱 EPC/強 SOC 摘要）**：弱電聲耦合、強 SOC、磁序溫度匹配製冷級、缺陷形成能高→載子可控。`distill/04` 同時指出：部分「ML 篩選」稿為規則引擎/硬編碼示意，非可直接採信之預測工具（定量需回讀原始檔與外部驗證）。

### 2.2 TI 作為低溫量子傳輸線之本機模型（TIRC/TEM） `[本機來源][本機模型]`
- 來源：`references/04_量子傳輸線工程.md`、`topo/distill/07_TEM波與拓撲傳輸線.md`、`/home/sam/物理模擬/topo/拓撲/034mK至10K.md`、`/home/sam/物理模擬/topo/拓撲絕緣體TEM波.md`。
- **優勢（條件性）**：自旋-動量鎖定→背散射抑制（TRS 下）→潛在低耗散/彈道傳輸；4 mK 下熱激發抑制、拓撲保護更完整；體/面電導比隨降溫改善（前提：體導被抑制）。
- **挑戰**：本征缺陷導致體電導短路表面態；薄膜品質、接觸電阻、超導電極界面、氧化控制；微波/CPW 實作需考慮表面電導率張量、有效介電與衰減。
- **表面電導模型（本機 TIRC 敘述）**：
  - `σ_s(ω) = σ_DC/(1 + iωτ) + σ_H(ω)`
  - `σ_DC = (e²/h)(k_F l_e)(v_F/π)`（以量子電導尺度 × 參數表示）
  - `σ_0 = e²/h ≈ 38.7 μS`，`R_K = h/e² ≈ 25.8128 kΩ` `[計算/示例: 標準常數]`
  - CPW：`ε_eff ≈ (ε_air+ε_sub)/2`（加 TI 表面層修正），`β = ω√(L'C')`，`Z_0 = √(L'/C')`（50 Ω 設計準則同傳統 CPW）；薄膜厚度 < 相干長度時電導量子化修正 `[本機模型]`。
- **溫區窗口**：4 mK–10 K 下 `k_B T ≪ E_g(~0.3 eV)`，熱激發跨體隙受抑；10 mK–4 K 相干條件更佳 `[本機模型]`。
- **本機整合線索**：TI Josephson 結整合進超導量子電路（Nano Lett. 2022 / arXiv:2007.04224，`[本機引用線索]`）；陽明交大 TI-Nb 共面波導 10 GHz 插入損耗 < 1 dB @1.5 K（`[本機來源]`，實驗條件/重現性待原始報告核對）；量子互連主流仍為低損耗同軸/柔性纜，TI 通道屬前瞻探索 `[本機來源]`。
- **`distill/07` 可靠性提醒**：TEM 波/拓撲傳輸線相關腳本存在實作錯誤與假設不一致（如解包/未定義量/常數與 `ε_eff` 不一致等），**機制可路由、模擬器數值不可直接採信** `[本機來源]`。

### 2.3 低溫量子傳輸線基線製程與材料（對照組） `[本機來源]`
- 來源：`量傳線/NbTi原物料/製程節點.md`、`多芯絞合製程.md`、`柔線/crioFlex製程.md`、`柔線/cf3多層結構製程.md`、`溫區擬合/07_材料介電與低溫工藝/Ag傳輸線規格NbTi.md`、`三視圖/柔性/驗證/對標CF3規格電性熱負載物理推導.md`（熱負載框架）。
- **NbTi 線材/電纜鏈**：VAR/EBM 熔煉與均質化 → 多芯（filaments）+ Cu/CuNi 基體 + Nb barrier → 熱擠壓/冷抽拉與熱處理 → 絞合/絕緣/穩定化 → 測試（I_c, T_c, S 參數, 熱負載）。`[本機來源]`
- **柔性低溫微波互連（crioFlex/CF3 類）**：Polyimide（Kapton）介電 + Ag（驅動/寬頻，低溫高導但非超導）或 NbTi（≤~4K 超導段，低熱導/低損耗路徑）之 stripline 疊層；典型工作 10 mK–400 K、薄型/小彎曲半徑、分溫階熱負載控制、通道相位匹配與串擾/屏蔽設計。`[本機來源]`
- **Ag vs NbTi 分工（本機規格筆記）**：Ag 適高頻驅動/讀取與跨溫區熱化鏈（熱導較高）；NbTi（T_c≈9.2 K）適 4K 以下 flux bias/低熱負載超導路徑（熱導較低、DC 電阻趨零，RF 損耗仍受多因素影響）。`[本機來源]`
- **熱負載物理基線**：`Q=(A/L)\int_{T_c}^{T_h}\kappa(T)dT` 與分溫階預算為本 repo 既有驗證框架（heatload-distill/SSOT；D4=A 邊界適用）。`[本機來源]`

## 4. 物理計算與機制驗證（條件性）

### 4.1 量子電導尺度 vs 傳輸線阻抗 `[計算/示例][本機模型]`
- 常數：`G_0 = e²/h = 3.874e-5 S`，`R_K = h/e² = 25812.8 Ω`（單自旋通道量子電阻尺度）；理想量子化通道導電與巨觀 50 Ω 微波傳輸線阻抗匹配分屬不同設計層級。
- **意涵**：TI「低耗散/彈道」敘述常指特定通道與條件（邊緣/表面態、相干長度、接觸與模式匹配）；不能直接等同於宏觀 50 Ω CPW 在 GHz 下自動低損耗。需以 `σ_s(ω)`、幾何、介電損耗與接觸損耗共同評估 `[本機模型/假設敏感]`。

### 4.2 趨膚深度與導體/材料狀態（示例） `[計算/示例]`
- 公式：`δ = sqrt(2ρ/(ωμ0))`（正常金屬趨膚效應，均質近似）。
- 2026-11-20 本機計算（示例參數，**非** 4 mK 實測 ρ；低溫 RRR/超導態會大幅改變）：

| 材料/假設 | 1 GHz δ (µm) | 5 GHz δ (µm) | 10 GHz δ (µm) |
|---|---:|---:|---:|
| Cu ~RT (ρ=1.7e-8 Ω·m) | 2.075 | 0.928 | 0.656 |
| Ag ~RT (ρ=1.6e-8 Ω·m) | 2.013 | 0.900 | 0.637 |
| Cu RRR~100 等效示例 (ρ=1.7e-10 Ω·m) | 0.208 | 0.093 | 0.066 |
| NbTi 正常態示例 (ρ=6e-7 Ω·m) | 12.328 | 5.513 | 3.898 |

- **解讀**：GHz 下電流集中於表層；TI 若以~nm 級表面態導電，與「電流集中於薄表層」在幾何尺度上可形成耦合設計空間，但**實際 RF 損耗**取決於 `σ_s(ω)`、體電導旁路、介電/輻射損耗與介面；超導 NbTi 在 T<T_c 時 DC→0 但微波表面阻抗/介電損耗仍需完整模型與量測 `[假設敏感]`。

### 4.3 熱負載與溫區約束（與互連選材耦合） `[本機來源][本機模型]`
- 傳導熱負載：`Q=(A/L)\int_{T_c}^{T_h}κ(T)dT`（分溫階）。TI/金屬/介電堆疊若用於跨溫區互連，必須同時滿足微波性能與各級冷卻功率預算；本 repo 既有結論顯示材料 κ(T) 積分與幾何/長度強烈影響熱流 `[本機來源]`。
- NbTi 在超導態熱導低於正常金屬（利於阻熱）而 Ag 熱導較高（利於熱化但增熱負載風險）之分工，與現行低溫傳輸線設計一致 `[本機來源]`；TI 薄膜通道的**系統級**熱學優劣需含基板/介電/封裝與接觸整體評估 `[待查核]`。

### 4.4 製程-性能因果鏈（機制級驗證） `[本機來源][arXiv檢索][本機模型]`
- `MBE/濺鍍成長品質` → 載子遷移率、缺陷密度 → `體導/面導比`。
- `Se 空位/反位/摻雜` → 費米能位置與體載子 → **可短路表面態**（p-type Bi₂Se₃ 摻雜調控顯示費米能可工程化 `[arXiv檢索]`）。
- `原位 Se 帽層 / ALD Al₂O₃ / 真空或手套箱傳輸` → 抑制氧化 → 保持表面態輸運 `[本機來源][本機引用線索]`。
- `介電基板整合（如 SiO₂ 上有序 Bi₂Se₃）` → 與 CPW/微波結構製程相容性提升 `[arXiv檢索]`。
- `接觸/超導電極（Au, Nb/Ti 過渡）` → 接觸電阻與近鄰效應 → 決定 RF/直流可用性 `[本機來源][假設敏感]`。

## 6. 適用邊界、失效情境與反例/風險

- **適用（較有利）**：低溫（抑制熱激發）、高品質薄膜與有效體導抑制、嚴格鈍化與惰性傳輸、接觸/介面受控、對拓撲通道/自旋相關功能有明確需求之原型元件。
- **需謹慎**：GHz 寬頻 50 Ω 多通道互連（損耗、相位/Skew、串擾、熱負載須全鏈路達標）；製程放大與一致性；磁場/磁性摻雜對 TRS 與保護條件的影響。
- **失效/不成立**：體載子主導輸運（缺陷/費米能未控）；表面氧化/污染；接觸電阻或介面損耗過大；將理論 `e²/h` 通道直接等同宏觀低損耗匹配線路；在缺 κ(T)/S 參數/幾何資料下宣稱熱或電性能優於 CF3/NbTi 基線。
- **遷移/反例提示**：`Bi₂Se₃` 電壓脈衝可誘導可擦除超導性 `[arXiv檢索]` → 顯示狀態可調亦意味操作穩定性需驗證；「topological coaxial cable」理論模型（Weyl/axion）不可直接等同 Bi₂Se₃ 薄膜 CPW 製程器件 `[假設敏感]`。
