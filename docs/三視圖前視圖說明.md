# 三視圖/前視圖.py 繪製功能說明

## 檔案位置
`/home/sam/量傳線/三視圖/前視圖.py`

## 功能
依 CF3 傳輸線規格繪製前視圖（X-Z 截面），回傳 matplotlib Figure。

## 規格參數（CF3_SPEC）

| 參數 | 值 | 說明 |
|---|---|---|
| channels | 8 | 通道數 |
| pitch_mm | 2.0 | 通道間距 (mm) |
| line_width_um | 35.0 | 訊號線寬 (μm) |
| total_width_mm | 17.0 | 總寬 (mm) |
| length_mm | 200.0 | 傳輸線長度 (mm) |
| dielectric_thickness_mm | 0.129 | 介電層厚度 (mm) |
| signal_thickness_um | 2.0 | 訊號線厚度 (μm) |

## 使用方式

```python
import sys
sys.path.insert(0, "/home/sam/量傳線/三視圖")
from 前視圖 import 繪製前視, CF3_SPEC

# 預設 CF3 規格
fig = 繪製前視()
fig.savefig("front.png", dpi=150)

# 自訂規格
custom = dict(CF3_SPEC, channels=16, pitch_mm=1.0)
fig = 繪製前視(custom)
```

## 直接執行

```bash
cd /home/sam/量傳線/三視圖
python 前視圖.py
# 輸出 前視圖.png
```

## 回傳
- `matplotlib.figure.Figure`，可 `st.pyplot(fig)` 或 `fig.savefig(...)`。
