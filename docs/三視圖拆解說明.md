# 三視圖獨立繪製模組說明

## 檔案
- `三視圖/前視圖.py`：`繪製前視(佈局=None, spec=None)`
- `三視圖/側視圖.py`：`繪製側視(佈局=None, spec=None)`
- `三視圖/上視圖.py`：`繪製上視(佈局=None, spec=None)`
- `三視圖/組合.py`：`繪製三視(...)`、`組合三視圖(...)`

## 混合使用範例

```python
import sys
sys.path.insert(0, "/home/sam/量傳線/三視圖")
from 前視圖 import 繪製前視
from 側視圖 import 繪製側視
from 上視圖 import 繪製上視

# 單獨
fig_front = 繪製前視()

# 組合
from 組合 import 繪製三視
前, 側, 上 = 繪製三視()
```

## 規格
預設使用 CF3 規格（8 通道、pitch 2mm 等），可傳入 `spec` dict 或 `佈局` (LayoutCalculator)。
