# 使用說明（全功能流程）

## 安裝

```bash
pip install -r requirements.txt
```

## 啟動

```bash
streamlit run app.py
```

瀏覽器開啟 http://localhost:8501，由左側選單選擇功能模組。

## 全功能流程總覽

1. **規格產生器**：輸入通道數/Pitch/線寬等 → 產生 Excel 規格書
2. **三視圖**：繪製前/側/上視圖 → 匯出 Excel
3. **三視圖進階**：智慧標註側視圖
4. **低溫超導**：NbTi 串擾分析 + Bloch-Grüneisen 電阻率
5. **熱負載**：熱負載曲線 + 回推溫區長度
6. **熱負載回推**：回推模型比較
7. **熱負載FLAX**：FLAX 2023 熱負載
8. **熱負載Raicu**：Raicu 同軸熱負載（含總熱負載）
9. **多目標優化**：串擾 vs 熱負載 Pareto（支援代理模型加速）
10. **RL 優化**：PPO 閉環優化
11. **代理模型+LLM**：代理模型預測 + LLM 參數生成
9. **整合元件**：元件清單
10. **傳輸線規格**：CF3 / FPC / Uleam1
11. **其它**：微帶線寬、電報員、波導、串擾
12. **HJ串擾**：HJ 模型 6 圖
13. **多層結構**：動態多層結構視圖
14. **閉環量傳線**：Loop Engineering
15. **智慧佈局**：優化三視圖 + Excel

## 各功能操作流程

### 規格產生器 (page 2)
1. 側邊欄設定通道數、Pitch、線寬、總寬、長度
2. 點擊「下載 Excel」取得 spec.xlsx

### 三視圖 (page 1)
1. 設定幾何參數
2. 選擇前/側/上視圖
3. 匯出頁面下載 Excel 規格書

### 低溫超導 (page 3)
1. 設定 NbTi 幾何與物理參數
2. 查看 NEXT/FEXT 串擾圖與 Lk/Z0
3. 調整溫度查看 Bloch-Grüneisen 電阻率

### 熱負載 (page 4)
1. 輸入 f01 等參數查看熱負載曲線
2. 回推頁面輸入熱導率/截面積/溫差/熱負載取得長度
3. 「NIST 9 係數模擬」分頁：選材料(9 係數 κ(T))、溫區/幾何/衰減/P_in 計算多溫區穩態熱負載與 κ(T) 曲線

### 熱負載 NIST9 模擬 (page 20, 新平台)
1. 來源：`src/量傳線設計/核心/熱負載NIST9.py` + `~/.opencode/skills/heatload-coff-nist/scripts/{coeff_data,thermal_load}.py`
2. 功能：κ(T) 曲線、∫κdT 曲線、材料比較、多溫區穩態熱負載 (Q_solid+Q_rf)、參數/材料掃描
3. 注意：僅使用具固定 9 係數且有來源/範圍之材料；NbTi(Cri/oFlex3) 為 runtime 擬合無固定係數

### 熱負載Raicu (page 19)
1. 選擇溫度級查看靜態熱負載
2. 輸入 qubit 數查看處理器線數與總熱負載圖

### 熱負載/pages (舊模組目錄，保留原檔 + NIST9 整合)
- `10nist低溫庫.py`: NIST 9 係數材料庫/κ(T)/∫κdT/比較/熱負載估算（原檔備份 `10nist低溫庫_legacy.py`）
- `30nist9_熱負載模擬.py`: NIST9 模擬與掃描
- `31nist9_polyfit_可靠度.py`: 顯示 `docs/polyfit_可靠度驗證.md/json`
- `_nist9_共用.py`: 共用層（D4/D5）
- `16柔性八階擬合.py`: 原 runtime polyfit 頁面保留；可靠度見驗證報告與 31 頁（備份 `16柔性八階擬合_legacy.py`）

### 視覺化與演示（易懂規格 + 離線 demo + Excel）
- 規格：`docs/NIST9_視覺化規格.md`（由重構文件萃取：目標/決策 D1-D6、架構、模型、API、可靠度與交付）
- 產生器：`scripts/nist9_viz_demo.py`（必要輸入 `docs/polyfit_可靠度驗證.json`；可選載入 NIST9 核心/技能引擎取樣曲線與熱負載，不可用則降級並記錄 `samples.errors`）
- 輸出：`docs/nist9_viz_data.json`（資料快照）、`docs/nist9_viz_demo.html`（自包含離線，純 HTML/CSS/JS+SVG，無外部 CDN）
- Excel 版（同呈現流程）：`scripts/nist9_viz_excel.py` → `docs/nist9_viz_demo.xlsx`（由 `nist9_viz_data.json` 產生，stdlib 無額外依賴）
- 視圖/分頁：總覽與決策、計算模型、交付清單、κ(T)/∫κdT 曲線樣本、材料比較/多溫區熱負載分解、polyfit 可靠度（基準/敏感度/係數對照）、檔案與 API 規格
```bash
python3 scripts/nist9_viz_demo.py      # html + data snapshot
python3 scripts/nist9_viz_excel.py     # excel 版（同呈現流程）
# 開啟 docs/nist9_viz_demo.html 或 docs/nist9_viz_demo.xlsx
```

## 程式化使用範例

```python
import sys
sys.path.insert(0, "src")

from 量傳線設計.核心.規格產生器 import 產生規格書
from 量傳線設計.輸出入.excel匯出 import 試算表轉bytes

佈局, 試算表 = 產生規格書(通道數=8, 訊號間距=2.0)
with open("out.xlsx", "wb") as f:
    f.write(試算表轉bytes(試算表))
print("已輸出 out.xlsx")
```

```python
from 量傳線設計.核心.低溫超導 import 模擬NbTi串擾
r = 模擬NbTi串擾(w_um=50, d_nm=100, s_um=100)
print("Z0 =", round(r["Z0"], 2))
```

```python
from 量傳線設計.核心.熱負載 import 回推溫區長度
L = 回推溫區長度(熱導率=0.1, 截面積=1e-6, 溫差=50.0, 熱負載_W=1e-6)
print("L =", round(L, 4), "m")
```
