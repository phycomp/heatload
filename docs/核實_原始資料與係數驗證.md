## 2. 核實 B：用 fitting 公式驗證 53 筆 `c0..c8`

### 2.1 用語糾正（先修正事實基礎）

- **不是「54 筆 `c0..c8`」**，而是 **53 筆固定 9 係數 + 1 筆例外**。
- 例外為 `NbTi (Cri/oFlex 3)`：`coeffs = None`，屬 `runtime_polyfit`（執行期才擬合），**自固定係數的數值關係中排除**。
- 因此正確表述為「54 筆 raw materials 中，53 筆具固定 9 係數」。

### 2.2 概念澄清：fitting 公式能證明什麼、不能證明什麼

fitting 公式本身**就是模型形式**（`log₁₀κ = Σ cₙ (log₁₀T)ⁿ` 的 log 多項式；Cu 另有 rational 式），`c0..c8` 只是**參數**。公式與參數**不含原始量測點**，因此無法用來證明係數「正確」；能驗證的是「**自洽性**」，不是「**可信度**」。

| 可以驗證（本次有做） | 不能驗證（本次不做、也不宣稱） |
| --- | --- |
| 9 係數皆為有限數值、結構完整 | 係數是否物理正確 |
| `valid_range_K` 是否合理、是否與 `equation_type` 相符 | 係數是否為該材料的最佳擬合 |
| 區間內 `κ(T) > 0`、有限、光滑 | 是否重現原始量測數據（未持有全部原始點） |
| 區間內熱導積分是否有限 | 可信度、不確定度、外推可靠度 |
| rational 式分母是否出現極點 | 新量測、新實驗結論 |
| 係數是否與溯源（NIST / Raicu / Cri）**逐值一致** | 上游文獻本身是否正確 |

方法上明示：**本次未重擬合、未造數據、未宣稱物理正確。**

### 2.3 方法

1. 自 `docs/9coeff_4step_flow.json` 的 `raw_materials` 取出 54 列，識別 `coeffs_c0_c8 is None` 的 1 列（NbTi）並排除，得 53 筆固定係數樣本。
2. 對每筆做結構檢查：9 係數存在且有限、`valid_range_K` 合理、`equation_type` 對應正確。
3. 在 `valid_range_K`（缺省時用合理預設區間）內掃描 `κ(T)`：檢查 `κ > 0`、有限、光滑、熱導積分 `∫κ dT` 有限；`rational_copper` 類別額外檢查分母極點。
4. 溯源逐值比對：與 NIST、Raicu、Cri/oFlex 來源版本對照 `c0..c8`。
5. 交叉檢查（僅提示、不作為 fail 判定）：材料間內部一致性、重複係數組、手冊數量級、擬合形態特徵、溯源路徑可用性。

### 2.4 結果統計

| 檢查項目 | 結果 |
| --- | --- |
| 樣本數（固定 9 係數） | **53**（另 1 筆 `NbTi (Cri/oFlex 3)` 為 `runtime_polyfit`，排除） |
| `equation_type` 分佈（54 列） | `log_polynomial` 48、`rational_copper` 5、`runtime_polyfit` 1 |
| 結構檢查（9 係數有限、`valid_range` 合理） | 53/53 通過 |
| 區間行為（`κ > 0`、有限、光滑、積分有限、rational 分母無極點） | 53/53 通過 |
| 溯源逐值比對 | NIST **48/48**、Raicu **4/4**、Kapton **1/1**，全等 |
| 整體 | **53/53 pass（僅代表自洽）** |

### 2.5 代表端點（`κ`，單位 W/m/K）

| 材料 | 低端 | 高端 |
| --- | --- | --- |
| Cu OFHC RRR100 | 642 | 396 |
| SS304 | 0.27 | 15.3 |

### 2.6 被 flag 清單（「自洽卻不可信」的反例）

> 以下 flag 不推翻 53/53 的結構結論，而是界定該結論的**效力上限**。

**(1) 內部矛盾（同一物質、不同列給出不一致參數）**

| 對照 | 數值 | 差異 |
| --- | --- | --- |
| Teflon (PTFE) vs Raicu dielectric (PTFE) | 0.0596 vs 0.2728（293 K） | 約 **4.6×** |
| Polyamide (Nylon) vs Raicu dielectric (PTFE) | 係數**完全相同** | 疑上游誤植 |
| Polyimide (Kapton) vs Kapton (Cri/oFlex 3) | 0.1919 vs 0.1521 | 約 **26%**（來源不同） |

**(2) 重複係數組：7 組、涉及 21 筆**

| # | 共用同一組係數的材料 |
| --- | --- |
| 1 | Al 1100 / 6061 / 6063 |
| 2 | SS 304 / 304L / 310 / 316 |
| 3 | Ni 鋼 2.25 / 3.25 / 5 / 9 |
| 4 | Glass Fabric / Glass mat / Polyurethane / PVC |
| 5 | Balsa = Teflon |
| 6 | Kevlar Composite = Fiber |
| 7 | Polyamide = PTFE |

物理上不同合金/材料共用同一組 9 係數並不合理；此現象表示部分列為**類別代表值**而非逐材料擬合。

**(3) 手冊數量級交叉：24 筆中 10 筆待溯源**

- 例：Al3003-F 差約 **0.028×**、Sapphire 差約 **4.4×**。
- 此對照使用**一般手冊記憶值、非本機量測**，故僅作提示，**不作為 fail 判定**。
- 另有 **22 筆**係數呈整數級、或僅 4–5 個非零項的**佔位擬合特徵**（非典型全項擬合結果）。

**(4) 溯源文件路徑已漂移**

- `coeff_data.py` docstring 與 `source` 欄引用的 `量傳線/熱負載/pages/10nist低溫庫.py` 等路徑，實際檔案已移至 `archive/熱負載/pages/`；部分溯源另指向 `溫區擬合/03_…`。
- 逐值比對對 **archive 版全等**，故結論為「SSOT 忠實抄錄」；但「文件寫的路徑」與「實際路徑」不一致，屬**可追溯性缺陷**（不影響數值，影響可驗證性）。

### 2.7 邊界宣告

- 本次僅涵蓋：**結構完整性 + 區間內行為合理性 + 來源逐值一致**。
- 明確**不是**：重擬合、物理正確性證明、新量測、溯源替代品。
- `Raicu rho inner (Table 6)` 的 `category` 為 rho(T)（電阻率，輸出 Ω·m，量級約 1e-7）。使用端必須**依 `quantity` 分流**，不可與 κ(T) 混用。
- 既有 `docs/polyfit_可靠度驗證.json` 顯示：Kapton 儲存係數與重擬結果 `max|Δc| ≈ 79.48`，且 `k(20 mK)` 外推極度敏感（cond(V) ≈ 1.3e7）；亦即**結構通過無法排除同類偏差**，`53/53 pass` 不得被引用為可信度證明。

後續建議（不在本次範圍）：

1. 修正 `coeff_data.py` 的溯源路徑（補 `archive/` 前綴），恢復可追溯性。
2. 針對 §2.6 (2) 的 7 組重複係數，逐組確認是「類別代表值」還是「上游誤植」。
3. 針對 §2.6 (3) 的 10 筆待溯源項，以正式文獻（而非手冊記憶值）逐筆核對。
4. 若需「可信度」層級結論，必須另做重擬合與不確定度分析，不能沿用本備忘錄。
