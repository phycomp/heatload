## 三、擬合數學形式

**NIST 低溫材料數據庫標準格式**：

$$\log_{10} k(T) = \sum_{n=0}^{8} c_n (\log_{10} T)^n$$

即：

$$\log_{10} k(T) = c_0 + c_1 (\log_{10} T) + c_2 (\log_{10} T)^2 + \cdots + c_8 (\log_{10} T)^8$$

**還原為 k(T)**：

$$k(T) = 10^{\left[\sum_{n=0}^{8} c_n (\log_{10} T)^n\right]}$$

**論文係數對應**：

## 四、最小二乘擬合

**線性問題**（在 log-log 空間）：

$$\mathbf{y} = \mathbf{X} \mathbf{c} + \mathbf{\epsilon}$$

$$\mathbf{c} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

**Python 實現**：

```python
import numpy as np

# 測量數據（預處理後）
x = np.log10(T_measured)   # log10(T)
y = np.log10(k_measured)   # log10(k)

# 8 階多項式擬合（numpy.polyfit 返回降冪排列）
coeffs = np.polyfit(x, y, 8)  
# coeffs = [c8, c7, c6, c5, c4, c3, c2, c1, c0]
# 對應:  [ i,  h,  g,  f,  e,  d,  c,  b,  a]

# 還原論文格式
a, b, c, d, e, f, g, h, i = coeffs[::-1]

# 計算擬合值
y_fit = np.polyval(coeffs, x)
k_fit = 10**y_fit
```

## 五、為何需要 8 階？為何需要 7 位有效數字？

**8 階的原因**：

- 白銅合金熱導率行為複雜：
  - 高溫 (>50K): 電子熱導主導，$k \propto T$
  - 中溫 (10-50K): 電子-聲子散射，過渡區
  - 低溫 (<10K): 雜質散射，$k \propto T^2$ 或 $T^3$
- 單一冪律無法描述全溫區，需要高階多項式捕捉多個轉折

**7 位有效數字的原因**：

- 高溫端 $x = \log_{10}(300) \approx 2.48$，$x^8 \approx 1500$
- $c_8 = -0.5266892$ 乘以 $x^8 \approx 1500$ 後對 $y$ 貢獻達 ~800
- 若截斷到 3-4 位，高階項誤差被放大，高溫端 $k(T)$ 明顯偏差
- 截斷敏感性：3 位 → 誤差 10-50%；**7 位 → 誤差 < 0.1%**

## 六、低溫外推方法

**問題**：擬合僅覆蓋 2K-300K，但 cryostat 需要到 20mK！

**論文方法**：直線外推到原點

```
log10(k)
   │
   │     ● 300K 數據
   │    ╱
   │   ╱  ← 8 階多項式擬合區間 (2K-300K)
   │  ╱
   │ ╱
   │╱ ● 2K 數據 (最低測量點)
   ││
   ││──────→ 直線外推到原點
   ││
   └┴────────────────→ log10(T)
     0   0.3   2.0   2.5
          ↑
       log10(2K)
```

**外推公式**（對 $T < T_{min}$）：

$$k(T) = T^{\alpha}, \quad \alpha = \frac{\log_{10} k_{min}}{\log_{10} T_{min}}$$

**論文警告**：此程序**可能高估**低溫熱導率，因實際數據在 2K 附近的斜率比直線更陡。
