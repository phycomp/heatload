這份文件是 **Montana Instruments 發布的《Cryogenic Wiring Guide》（低溫佈線指南）**，發表於 2021 年 9 月，主要針對低溫實驗系統（如 Cryostation）中的佈線實務提供技術建議。以下為各章節的摘要與示意圖說明：

## 1. Wire Insulation（導線絕緣）

**摘要**：低溫系統中多數佈線問題源自絕緣層損壞。絕緣層極薄（可薄至 2.5 µm），在高使用頻率區域（如熱夾具下方）或使用尖銳鑷子時容易刮除。建議使用 **特氟龍頭鑷子** 並在顯微鏡下操作。避免在熱夾具下使用特氟龍膠帶作為防刮保護，因其熱隔離性會導致平台基溫升高；若需電氣隔離，可使用 **Kapton 膠帶** 包裹 RF 同軸電纜。

**示意圖說明**：
```
[室溫端] ──導線──► [熱夾具區域]
              ▼
        ┌─────────────┐
        │❌ 特氟龍膠帶│ ← 熱隔離，導致基溫上升
        │✅ Kapton膠帶│ ← 允許熱傳導，提供電氣隔離
        └─────────────┘
              ▼
        [低溫平台]
```

## 2. Electrical Isolation（電氣隔離）

**摘要**：敏感電性測量必須將測量導線與潛在雜訊源（如電壓脈衝線）隔離，以避免串擾。電壓型敏感導線應與電流型導線分開，因為高電流源會產生顯著電壓梯度（熱電效應）。因此，敏感電壓導線的散熱器應與電流導線的散熱器分開。

**示意圖說明**：
```
    [雜訊源：電壓脈衝線]
           ▼ 電磁耦合/串擾
    ┌──────────────────┐
    │敏感測量導線區域  │
    │┌──────┐  ┌──────┐│
    ││電壓線│  │電流線││ ←應分開佈設
    │└──┬───┘  └──┬───┘│
    │   └─────────┘    │ 熱電效應導致
    │   [共用散熱器 ❌]│  的電壓梯度
    │   [獨立散熱器 ✅]│
    └──────────────────┘
```

## 3. Grounding（接地）

**摘要**：不當接地是敏感電性測量中最大的雜訊來源。原則上所有儀器應僅有 **單一接地點**，以避免「接地迴路」（ground loops）——即不同電路間透過非零電阻的共同連接，導致各電路基準電壓被拉高並產生環流電流。常見問題是多個儀器插在不同電源排插上；解決方法是將所有儀器隔離並使用單一共用地。但極敏感電子設備（如奈伏特計）不應與高功率設備共用接地，可使用 **共模隔離** 或高共模阻抗電流計來減少接地環流。

**示意圖說明**：
```
    接地迴路問題：

    [儀器A]───┬────[電源排插1]──地線──┐
              │                       │
              └────[電源排插2]──地線──┼──► 地迴路環流 ❌
    [儀器B]───┬───────────────────────┘
              │
    [儀器C]───┘

    正確做法：

    [儀器A]──┐
    [儀器B]──┼──► [單一共用地點] ◄── 所有地線匯集於一處 ✅
    [儀器C]──┘

    敏感設備隔離：
    [奈伏特計]──[隔離器/高共模阻抗電流計]──[單一地點] ✅
```

## 4. Twisted Pair（雙絞線）

**摘要**：當平行共模線（承載大小相等、方向相反的信號）靠近交流電流源導線時，交流磁場會在共模線中感應出電流，造成串擾。解決方法是將共模線 **絞合在一起**，使各段迴路面積產生的感應電流相互抵消。絞距應小於 **20 倍導線直徑**。可用電鑽夾具固定兩端並以定速絞繞製作。

**示意圖說明**：
```
    平行佈線 產生串擾

    AC電流源 ────────►

    共模線A ─────────►  大面積迴路
    共模線B ◄────────   ═════════════► 感應電流 ❌

    雙絞線（抵消串擾）：

    AC電流源 ────────►

    A╲B╱A╲B╱A╲B╱A╲B╱  小面積迴路
    B╱A╲B╱A╲B╱A╲B╱A   ↻ 各段感應電流方向相反，相互抵消 ✅

    絞距規格：每扭轉間距 < 20 × 導線直徑
```

## 5. Minimizing Thermoelectric Effects（最小化熱電效應）

**摘要**：當敏感電壓測量導線與電流導線共用散熱器時，兩者間的溫度梯度會因 **席貝克效應（Seebeck effect）** 產生不可忽略的電壓差——自由電荷載子會向較暖側移動。解決方法是盡可能使用 **低頻交流信號** 替代直流信號。

**示意圖說明**：
```
    [電流導線] 高電流產生焦耳熱
         ▼ 溫度梯度 T_hot > T_cold
    ┌─────────────────┐
    │    [共用散熱器] │
    │ 熱端 ◄───► 冷端 │
    │    ↑            │
    └────┼────────────┘
    [電壓測量導線] 席貝克電壓 V_seebeck 疊加於測量信號 ❌

    解決方案：
    DC信號 ──► 低頻AC信號 (如：f << 1Hz 或 鎖相放大器參考頻率)

    AC信號：V(t) = V_0 sin(ωt)
    席貝克電壓為DC偏移 → 可被AC耦合或鎖相技術濾除 ✅
```

## 6. Wiring with AC Signals（交流信號佈線）

**摘要**：在同一測量中同時使用交流電壓與電流線時，兩組導線間的雜散電容會導致不期望的相位移。應盡可能將電壓線與電流線分開。AC 實驗中應盡量使用 **RF 濾波器**。若製作客製被動元件用於 RF 實驗，屏蔽對屏蔽連接器必須水密以防 RF 輻射洩漏。若 RF 環境中同時存在 DC 測量導線，應遵循前述雙絞線方法。

**示意圖說明**：
```
    雜散電容導致相位移：

    [AC電流源]────────┐
                      │C_stray（雜散電容）
    [AC電壓測量線]────┘◄── 相位移 φ = arctan(ωC_strayR)

    正確佈局：

    區域A：AC電流線 + RF濾波器
    ═══════════════════════════
           [隔離間隙]
    ═══════════════════════════
    區域B：AC電壓線 + RF濾波器

    RF連接器：
    [外屏蔽層]══════[外屏蔽層]  ← 水密連接，防止RF輻射洩漏
         │              │
    [內導體]────────[內導體]

    DC線在RF環境中：使用雙絞線 ✅
```

## 7. Thermal Lagging/Anchoring（熱滯留/熱錨定）

**摘要**：為達到最低基溫，必須最小化外部熱負載，包括來自溫度計和加熱器導線的焦耳熱。熱錨定是將導線熱連接至具有足夠冷卻能力的冷點，使錨定點後方所有點達到共同溫度。方法包括將導線繞在銅線軸上並塗覆清漆，或用熱夾具壓緊。若無空間使用線軸，可使用低熱導率金屬（如磷青銅）並在較小熱夾具下錨定，保留足夠長度以形成高溫度梯度。關鍵在於選擇導線長度與截面積，使熱流$Q_{out}$低於平台冷卻功率。

**傅立葉熱傳導公式**：

- 微分形式$δQ_{out} = k(T)·A·(δT/l)$
- 積分形式$Q_{out} = (A/l)·∫k(T)dT$

**示意圖說明**：
```

   熱錨定架構 [室溫 300K]
         ▼
    ┌──────────────┐
    │ 30K輻射屏蔽層│◄── 第一熱錨定點（銅線軸+清漆）
    │   ┌──────┐   │
    │   │繞線區│   │   高熱導材料（銅）：快速導熱
    │   └──┬───┘   │
    └──────┼───────┘
           ▼
    ┌─────────┐
    │ 4K 平台 │    ◄── 第二熱錨定點
    │ ┌──────┐│
    │ │繞線區││      低熱導材料（磷青銅/錳銅）：限制熱流
    │ └──┬───┘│
    └────┼────┘
         ▼
    [樣品/溫度計]

    熱流平衡條件：Q_out < Q_cooling（平台冷卻功率）

    無線軸空間的替代方案：
    [30K端]──[長段磷青銅線]──[熱夾具錨定@4K]──[短段至樣品]
                    ↑
              低熱導率 → 高溫度梯度維持 (30K→4K)
```

## 9. Installation of Wiring（佈線安裝）

### Basics（基礎）
**摘要**：細規格導線安裝困難，需處理神秘短路、連接問題、熱負載與電子雜訊。要點：
- 焊接針端時僅剝除最小必要長度的絕緣層，避免未來短路
- 連接系統前用電壓表檢查新線束與所有電阻元件的連通性
- 避免將會釋放有害污染物的材料放入真空腔：塑膠、PVC、油漆、鋅、助焊劑、鉛、鎘等

### Practical Lagging Techniques（實用熱滯留技術）
**摘要**：熱滯留的目標是最大化冷熱表面間的接觸面積。使用清漆和線（如牙線）固定導線於冷表面。塗佈前需用酒精徹底清潔冷表面。可使用壓縮彈簧機構將導線壓緊於表面以確保足夠接觸力。

**示意圖說明**：
```
    熱滯留結構

    [冷表面（銅塊/平台）]
    ═══════════════════════
    │  導線 ──繞行──►   │
    │    ↓              │
    │  導線 ──繞行──►   │  ← 多圈繞行增加
    │    ↓              │    接觸面積
    │  導線 ──繞行──►   │
    ═══════════════════════
         ↑
    [清漆層] 固定導線並填充空隙
         ↑
    [牙線/綁線] 機械固定

    可選：壓縮彈簧
    ┌─────────┐
    │  彈簧   │──► 向下施力壓緊導線
    │   ▓▓▓   │
    └────┬────┘
         │
    [導線層]──[冷表面]
```

### Soldering Basics（焊接基礎）
**摘要**：焊接細導線與小針腳需在顯微鏡下使用精密鑷子操作。開始前應「鍍錫」烙鐵頭。準備好焊料、濕海綿以保持烙鐵頭清潔。文件附有一幅公開領域的焊接漫畫，以圖解方式說明良好焊點的製作方法。

**焊接漫畫內容說明**：
```
    焊接步驟流程圖（12格漫畫）：

    [準備階段]
    格1：工具準備 — 烙鐵、焊料、斜口鉗、零件、PCB
    格2：安全提示 — 烙鐵高溫注意！閱讀說明書，每次焊接前清潔烙鐵頭
    格3：固定零件 — 彎折引腳使零件固定於PCB上

    [操作階段]
    格4：穩定PCB — 注意下方表面，用輔助工具固定；可用焊料線圈代替第三隻手
    格5：加熱 — 同時加熱焊墊與引腳約1秒；先清潔烙鐵頭！
    格6：接觸 — 烙鐵頭同時接觸焊墊與引腳

    [送錫階段]
    格7：送錫 — 在烙鐵頭下方送入焊料，距離約1-3mm
    格8：持續 — 停止送錫後保持1秒，使焊料充分流動
    格9：檢查 — 良好焊點：覆蓋整個焊墊、不碰及其他焊墊、包覆引腳

    [收尾階段]
    格10：剪腳 — 用斜口鉗剪除多餘引腳；勿手持引腳（可能彈跳傷眼）
    格11：安全 — 焊錫煙霧無毒但應輕吹避開；引腳含鉛有毒，焊接後洗手
    格12：完成 — 每個零件焊於正確位置；良好連接確保電路正常運作
```

## 總結

本指南涵蓋低溫實驗佈線的七大核心議題：**絕緣保護、電氣隔離、單點接地、雙絞線抗干擾、熱電效應抑制、交流信號佈線、熱錨定技術**，並提供具體材料選擇數據與焊接操作規範，為低溫量測系統的雜訊控制與熱管理提供實務指導。
