## HFSS 建模方法

### 1. 電纜截面建模 (阻抗優化)

```
【理想設計 vs 實際製造】

理想意圖 (半圓形壓痕)          實際製造 (拋物線壓痕)
      ┌─────────┐                 ┌─────────────┐
     /  ○━━━━━○  \               /  ○━━━━━━━━━○  \
    /   ○ NbTi ○   \             /   ○  NbTi    ○   \
   │    ○ 0.003"○    │           │    ○  0.003"  ○    │
    \   ○━━━━━○   /             \   ○━━━━━━━━━○   /
     \─────────/                 \─────────────/
      半圓: y = √(r²-x²)          拋物線: y = kx²
      外導體貼近 PFA                 外導體開口更寬
      b_eff ≈ b_design             b_eff > b_design
      C = 2πε/ln(b/a)              C < 2πε/ln(b_eff/a)
      Z₀ ≈ 50 Ω                    Z₀ ≈ 60 Ω (偏高)

【HFSS 建模步驟】

Step 1: 實際截面輪廓提取
─────────────────────────
- 從製造顯微照片/剖面測量提取坐標點
- 用 Spline 曲線描繪拋物線輪廓
- 非理想圓柱/圓環，捕捉製造偏差

Step 2: 3D 全波模型
─────────────────────────
內導體:  圓柱 (NbTi, 變數 d_inner)
介電層:  PFA 圓柱 (εᵣ ≈ 2.0, 外徑 0.011" 固定)
外導體:  Spline 曲線 (拋物線, 厚度 1 mil)
邊界:    週期性邊界 (模擬無限長電纜)

Step 3: 求解器設定
─────────────────────────
模式:   Driven Modal
端口:   Wave Port (自動計算特性阻抗)
頻率:   4-8 GHz (MKID 工作頻段)
網格:   自適應加密 (λ/20 解析度)

Step 4: 參數化掃描
─────────────────────────
變量:   d_inner = [0.003", 0.004", 0.005", 0.006"]
輸出:   Z₀ vs d_inner 曲線

┌─────────────┬──────────────┬──────────────┐
│ d_inner     │ 理想半圓 Z₀  │ 拋物線實際Z₀ │
├─────────────┼──────────────┼──────────────┤
│ 0.003"      │ ~55 Ω        │ ~60 Ω  ← 前作│
│ 0.004"      │ ~50 Ω        │ ~55 Ω        │
│ 0.005"      │ ~45 Ω        │ ~50 Ω  ← 選擇│
│ 0.006"      │ ~42 Ω        │ ~47 Ω        │
└─────────────┴──────────────┴──────────────┘

選擇 0.005" 原因:
- 拋物線實際 Z₀ ≈ 53 Ω (接近 50 Ω)
- 0.006" 可能使理想情況下 Z₀ 過低
- 製造偏差可能進一步降低阻抗
- 不改變 PFA 外徑 → 保持線芯間距 3.56 mm
```

### 2. 端部過渡建模 (電感補償)

```
【電磁場模式轉換鏈】

同軸電纜          過渡板 (舊設計)           連接器
─────────       ─────────────────       ─────────
TEM 模式   →   CPW 模式 (不連續)    →   TEM 模式

電場分布:         電場分布:               電場分布:

┌───────┐        ┌──────────────┐        ┌───────┐
│ E→←E  │        │ E↓    ↑E     │        │ E→←E  │
│   ↑   │   →    │   Sig        │   →    │   ↑   │
│  Sig  │        │ Gnd   Gnd    │        │  Sig  │
│   ↓   │        │              │        │   ↓   │
│ E→←E  │        │ E↓    ↑E     │        │ E→←E  │
└───────┘        └──────────────┘        └───────┘

3D 圓柱對稱      2D 平面共面分布          3D 圓柱對稱G
(接地環繞)       (接地僅在兩側)            (接地環繞)

【問題分析】

3D→2D 突變:
- 接地從「環繞」變為「共面兩側」
- 接地路徑面積減小 → 電流密度增大
- 信號-接地重疊面積減小 → 電容 C 驟降
- 高頻時電抗 1/jωC 增大 → 淨感性主導
- 等效串聯電感: L_end ≈ 0.5-1 nH

2D→3D 再次突變:
- 兩次模式轉換 = 兩個串聯電感 L₁, L₂
- 反射: Γ ≈ jω(L₁+L₂) / 2Z₀
- S21 波紋: ~|Γ|² ∝ ω² → 隨頻率增大

【HFSS 端部過渡建模】

舊設計 (無電容耦合):
─────────────────────────
端口 1:  電纜端, Wave Port, 同軸模式
過渡區:  GCPW 結構, 長度 ~2 mm
         上層接地平面獨立, 不連接
         信號線上方無金屬
端口 2:  連接器端, Wave Port, CPW 模式
頻率掃描: 1-10 GHz

模擬結果 (舊設計):
┌────────┬────────┬────────┬─────────┐
│ 頻率   │ |S11|  │ |S21|  │ 備註    │
├────────┼────────┼────────┼─────────┤
│ 1 GHz  │ -25 dB │ -0.5dB │ 小反射  │
│ 4 GHz  │ -18 dB │ -1.5dB │ 反射增大│
│ 8 GHz  │ -12 dB │ -4.0dB │ 波紋顯著│ ← 問題
│ 10 GHz │ -10 dB │ -5.5dB │ 嚴重    │
└────────┴────────┴────────┴─────────┘

場可視化: 電場在過渡區前緣集中
          信號線上方無電場
          能量反射而非傳輸

新設計 (加入電容耦合):
─────────────────────────
修改: 上層 GCPW 兩側接地平面
      在信號線前方以 0.006" 間隙連接
      形成「上接地橋」

      舊設計:            新設計:
      G  S  G            G══S══G
      ── ─ ──            ═══════  ← 上接地橋
      │  │  │            │  ↑  │
      │  │  │            │  S  │  ← 信號線在橋下
      │  │  │            │  │  │

效果: 信號線上下均有接地
      → 信號-接地電容倍增 (C = C_bottom + C_top)
      → 電容抵消電感: C_coupling 與 L_end 形成 LC 諧振
      → 在設計頻段 4-8 GHz 呈現純阻性 (阻抗匹配)

模擬結果 (新設計):
┌────────┬────────┬────────┬────────┐
│ 頻率   │ |S11|  │ |S21|  │ 備註   │
├────────┼────────┼────────┼────────┤
│ 1 GHz  │ -30 dB │ -0.3dB │ 更小   │
│ 4 GHz  │ -28 dB │ -0.4dB │ 平坦   │
│ 8 GHz  │ -25 dB │ -0.7dB │ 波紋消 │ ← 消除
│ 10 GHz │ -22 dB │ -1.0dB │ 仍良好 │
└────────┴────────┴────────┴────────┘
```

## HFSS 優化的核心物理洞察

```
┌────────────────────────────────────────────────────────────┐
│  洞察 1: 拋物線壓痕的阻抗影響                              │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  理想同軸: Z₀ = (60/√εᵣ) ln(b/a)                           │
│  拋物線壓痕: b_eff > b_design (等效外半徑增大)             │
│  → Z₀_effective > Z₀_design                                │
│                                                            │
│  HFSS 發現: 拋物線使 Z₀ 升高 ~20%                          │
│  解決方案: 增大 a (中心導體) 使 ln(b_eff/a) 回到目標值     │
│  關鍵: 不改變 b (PFA 外徑) → 保持電纜截面/間距/密度不變    │
│                                                            │
├────────────────────────────────────────────────────────────┤
│  洞察 2: 端部過渡的電抗不平衡 (非純阻抗問題)               │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  傳統阻抗匹配 (如 λ/4 變換器) 無法解決此問題:              │
│  - 問題不是「阻抗值錯誤」                                  │
│  - 問題是「電容-電感失衡」 (電抗不平衡)                    │
│                                                            │
│  3D→2D→3D 模式轉換:                                        │
│  - 中心導體連續 → 電感路徑不變                             │
│  - 接地路徑突變 → 電容驟降                                 │
│  - 淨效果: 串聯電感 L_end                                  │
│                                                            │
│  HFSS 發現: 需要主動增加電容 (而非調整電感)                │
│  解決方案: 上接地橋形成 C_coupling                         │
│  諧振條件: ω₀ = 1/√(L_end × C_coupling) ≈ 6 GHz (頻段中心) │
│                                                            │
├────────────────────────────────────────────────────────────┤
│  洞察 3: 兩個優化是獨立但協同的                            │
├────────────────────────────────────────────────────────────┤
│  電纜本體優化: 解決 Z₀ 不匹配 → 消除電纜內部反射           │
│  端部過渡優化: 解決電抗不平衡 → 消除接口反射               │
│  前作總損耗: 7 dB = 電纜損耗 (~3 dB) + 端部反射 (~4 dB)    │
│  本工作損耗: 1.5 dB ≈ 純電纜損耗 (端部反射幾乎消除)        │
└────────────────────────────────────────────────────────────┘
```

## HFSS 模擬-實驗閉環流程

```
┌────────────────────────────────────────────────────────────┐
│              HFSS 模擬 → 設計 → 製造 → 測量 → 驗證         │
├────────────────────────────────────────────────────────────┤
│  1. 問題識別 (實測)                                        │
│     TDR: Z₀ ~60 Ω, S21: 7 dB @ 8 GHz, 波紋增大             │
│              ↓                                             │
│  2. 根因分析 (HFSS)                                        │
│     ├─ 截面模擬: Spline 拋物線 → Z₀ 偏高 20%               │
│     └─ 端部模擬: 3D→2D→3D 模式轉換 → L_end 電感            │
│              ↓                                             │
│  3. 參數化掃描 (HFSS)                                      │
│     ├─ d_inner: 0.003"→0.005" → Z₀ 從 60→53 Ω              │
│     └─ C_coupling: 0.006" 間隙 → 抵消 L_end                │
│              ↓                                             │
│  4. 設計變更                                               │
│     ├─ 中心導體: 0.003" → 0.005" (不變 PFA 外徑)           │
│     └─ 過渡板: 上接地橋 (0.006" 間隙)                      │
│              ↓                                             │
│  5. 樣品製造 (5 線芯, 1-ft, 手動)                          │
│              ↓                                             │
│  6. 實驗驗證                                               │
│     ├─ TDR: Z₀ ~53 Ω  (HFSS 預測 ~53 Ω) ✅                 │
│     ├─ S21: 1.5 dB @ 8 GHz (HFSS 預測 <2 dB) ✅            │
│     ├─ 波紋: 消除 (HFSS 預測消除) ✅                       │
│     └─ S41: <-40 dB (HFSS 預測類似) ✅                     │
│              ↓                                             │
│  7. 結論: HFSS 預測與實測高度吻合 → 方法有效               │
│     傳輸損耗改善 4x, 熱負載不變, 可商業化                  │
└────────────────────────────────────────────────────────────┘
```
