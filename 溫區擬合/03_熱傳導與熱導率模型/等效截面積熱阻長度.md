# 低溫傳輸線熱負載物理推導與 Aluminum Shielding 分析

## 一、核心問題**per channel**的正確理解

**❌ 錯誤理解**
• **per channel** 單根 AWG36 線
• 截面積 A = π × (0.0635 mm)² = 0.0127 mm²
• 回推長度僅數公分 → **與實際不符**

**✅ 正確理解**
• **per channel** 整個同軸通道
• 包含：中心導體 + 外屏蔽層 + 介電層
• 總有效截面積 $A_{channel}$ ≈ 0.06 ~ 0.25 mm²（約單根線的 5~20 倍）
• 回推長度數十公分 ~ 數米 → **符合實際**

## 二、同軸線截面結構

```
        ┌─────────────────────────────┐
        │      外護套 (不鏽鋼管)      │  ← 真空夾套，熱錨點
        │  ┌─────────────────────┐    │
        │  │ 外屏蔽(CuNi 編織網) │    │  ← 主要導熱路徑之一
        │  │  ┌───────────────┐  │    │
        │  │  │ 介電層(PTFE)  │  │    │  ← 熱阻層，低熱導率
        │  │  │ ┌───────────┐ │  │    │
        │  │  │ │ 中心導體  │ │  │    │
        │  │  │ │ (AWG36)   │ │  │    │  ← 信號傳輸路徑
        │  │  │ │ d=0.127mm │ │  │    │
        │  │  │ └───────────┘ │  │    │
        │  │  └───────────────┘  │    │
        │  └─────────────────────┘    │
        └─────────────────────────────┘
```

## 三、Wiedemann-Franz 定律推導

### Step 1: Wiedemann-Franz Law

對於金屬，熱導率 λ 與電導率 σ 的關係：

$λ = L₀ · T · σ = L₀ · T / ρ(T)$

其中：

- L₀ = 2.45 × 10⁻⁸ W·Ω/K²（Lorenz 數，普適常數）
- T = 絕對溫度（K）
- ρ(T) = 電阻率（Ω·m）

### Step 2: 熱傳導積分（沿線方向）

通過長度 L、截面積 A 的傳輸線，從 T_h 到 T_c 的熱流：

$$
Q = (A/L) · ∫λ(T)dT
  = (A/L) · ∫[L₀·T/ρ]dT
$$

假設在該溫度段內 ρ ≈ 常數：

$Q = (L₀·A / L·ρ) · (T_h² - T_c²) / 2$

### Step 3: 反推長度（已知 Q，求 L）

 $L = L₀ · A_{channel} · (T_h² - T_c²) / (2 · Q · ρ)$

**⚠️ 關鍵：$A_{channel}$ 是「整個通道」的有效截面積，非單根線截面積！**

## 四、CuNi 取代 Ag 的等效計算 已知條件

- 相同熱負載 Q（固定）
- 相同溫度段$T_h, T_c$
- CuNi 電阻率：$ρ_{CuNi} = 4.9 × 10⁻⁷ Ω·m$
- Ag 電阻率：$ρ_{Ag} = 1.5 × 10⁻⁸ Ω·m$

### 推導

$$
L_{CuNi} / L_{Ag} = ρ_{CuNi} / ρ_{Ag}
              = 4.9 × 10⁻⁷ / 1.5 × 10⁻⁸
              ≈ 32.7
$$

### 結論

| 比較項目 | 結果 |
|---------|------|
| 相同熱負載下 | CuNi 線長度需為 Ag 的 **~33 倍** |
| 相同長度下 | CuNi 熱負載僅為 Ag 的 **~3%** |

**應用**：CuNi 常用於「熱隔離段」（需要長距離低熱傳導），Ag 用於「低熱阻連接段」。

## 五、Aluminum Shielding 熱傳導分流

### 模型：Shield 與 Signal Line 並聯

```
              ┌─── Signal Line(Ag/CuNi) ───┐
        T_h ──┤                            ├── T_c
              └─── Al Shield ──────────────┘
```

### 並聯熱阻公式

$1/R_{total} = 1/R_{wire} + 1/R_{shield}$

$R = L / (λ·A) = 2L·ρ / [L₀·A·(T_h² - T_c²)]$

### Shield 長度計算（承擔全部 Q）

$L_{Al} = L₀ · A_{Al} · (T_h² - T_c²) / (2 · Q · ρ_{Al})$

### 典型參數

| 參數 | 數值 |
|-|--|
| Al 電阻率 (4K, RRR~100) | 2.5 × 10⁻⁹ Ω·m |
| Shield 截面積 | ~0.5 mm²（Ø2mm, t=0.1mm） |
| $L_{Al} / L_{Ag}$ 比值 | ≈ $(A_{Al}/A_{Ag}) · (ρ_{Ag}/ρ_{Al})$ ≈ **10×** |

**結論**：Al Shield 因電阻率極低（尤其低溫高 RRR），可用較短長度分流大量熱負載。

## 六、熱輻射計算（Stefan-Boltzmann）

### 兩平行表面間的淨輻射熱流

$Q_{rad} = ε · σ · A_{surf} · (T_h⁴ - T_c⁴)$

### 參數

| 參數 | 符號 | 數值 |
|------|------|------|
| Stefan-Boltzmann 常數 | σ | 5.67 × 10⁻⁸ W/m²/K⁴ |
| 發射率（拋光 Al） | ε | 0.03 |
| 表面積（圓柱側面） | A_surf | π · D · L |

### 300K → 50K 段輻射熱負載估算

$$
Q_{rad} = 0.03 × 5.67×10⁻⁸ × π × 0.002 × 0.3 × (300⁴ - 50⁴)
      ≈ 2.6 mW
$$

### 關鍵發現

| 溫度段 | 輻射熱負載 | 傳導熱負載 | 結論 |
|--------|-----------|-----------|------|
| 300K → 50K | ~2.6 mW | 2.7 mW | 輻射 ≈ 傳導，**不可忽略** |
| 50K → 4K | ~0.01 mW | 0.8 mW | 輻射僅傳導的 1%，**可忽略** |
| 4K 以下 | < 1 µW | 數 µW | 輻射**完全可忽略** |

**抑制方法**：多層 shield（MLI, Multi-Layer Insulation）可將輻射降低 10⁻³ ~ 10⁻⁴。

## 七、等效熱阻長度概念

### 問題：4K 以下 NbTi 段計算長度僅數毫米，是否合理？

### 實際稀釋製冷機結構

```
4K Plate ──[2cm NbTi 帶]── Still (0.6K)
Still ──[1cm NbTi 帶]── Cold Plate (100mK)
Cold Plate ──[1cm NbTi 帶]── Mixing Chamber (10mK)
```

### 解釋

1. **NbTi 在 <9.2K 為超導態**，直流電阻理論上為零
2. 圖中 NbTi 的「熱負載」實際來自：
   - **銅穩定層**的殘餘熱傳導
   - **接頭電阻**（超導-正常態界面）
   - **磁通流動電阻**（若有磁場或電流超過 Jc）
3. 計算出的「線長度」實為**等效正常態熱阻長度**，非實體線長

### 等效熱阻長度定義

$L_{eff} = L₀ · A · (T_h² - T_c²) / (2 · Q · ρ_{eff})$

其中 $ρ_{eff}$ 為**等效正常態電阻率**包含：

- 基體銅電阻
- 接頭電阻
- 磁通流動電阻

## 八、完整計算範例：300K → 50K 段

### 已知

• Q = 2.7 mW/CH
• T_h = 300K, T_c = 50K
• Channel：中心 AWG36 + 外屏蔽，總 A = 0.063 mm²
• ρ_Ag = 1.6 × 10⁻⁸ Ω·m
• L₀ = 2.45 × 10⁻⁸ W·Ω/K²

### 計算

```
L = L₀ · A · (T_h² - T_c²) / (2 · Q · ρ)

L = 2.45×10⁻⁸ × 0.063×10⁻⁶ × (300² - 50²)
   ───────────────────────────────────────
        2 × 2.7×10⁻³ × 1.6×10⁻⁸

L = 2.45×10⁻⁸ × 6.3×10⁻⁸ × 87,500
   ─────────────────────────────
        8.64×10⁻¹¹

L = 1.57 m
```

### 驗證

| 計算方式 | 截面積 | 回推長度 | 合理性 |
|---------|--------|---------|--------|
| 單根 AWG36 | 0.0127 mm² | 31 cm | ❌ 過短 |
| Channel 總截面積 | 0.063 mm² | **1.57 m** | ✅ 合理 |

## 九、總結

| 項目 | 關鍵結論 |
|------|---------|
| **per channel** | = 整個同軸通道（中心導體 + 外屏蔽），總截面積約單根線的 5~20 倍 |
| **CuNi 取代 Ag** | 相同熱負載下長度需增加 ~33 倍（ρ_CuNi/ρ_Ag ≈ 32.7） |
| **Al Shielding** | 並聯熱傳導路徑，長度約為信號線的 10 倍（因 ρ_Al << ρ_Ag） |
| **熱輻射** | 300K→50K 段不可忽略（≈ 2.6 mW），需多層 shield（MLI）抑制 |
| **等效熱阻長度** | 4K 以下 NbTi 的「線長」實為等效正常態熱阻，非實體線長 |
