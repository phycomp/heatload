我已經為您完成了完整的技術分析。以下是針對 **15mK 極低溫量子計算環境** 下，**RO4350B 硬板 + Kapton/PI 軟板** 軟硬結合板的膠材選擇與製程詳述：

## 一、核心挑戰分析

### 熱膨脹係數 (CTE) 不匹配（從 300K → 15mK）

| 材料 | X/Y 收縮 | Z 收縮 | CTE (室溫) |
|------|---------|--------|-----------|
| **RO4350B** | 0.20% | **0.73%** | 10-32 ppm/°C |
| **Kapton (PI)** | 0.40% | 0.40% | 20 ppm/°C |
| **Stycast 2850FT** | 1.05% | 1.05% | 35 ppm/°C |

**關鍵發現**：Z 軸不匹配達 **0.33%**，是最大風險點。RO4350B 的 Z 軸 CTE (32 ppm/°C) 遠高於面內 (10-12 ppm/°C)，這是陶瓷填充基材的特性。

## 二、推薦膠材 首選**Stycast 2850FT**（氧化鋁填充環氧樹脂）

| 物理參數 | 數值 | 備註 |

| **CTE (Tg 以下)** | **35 ppm/°C** | 關鍵參數 |
| 熱導率 | **1.25 W/m·K** | 優異，有助熱錨定 |
| 玻璃轉化溫度 Tg | 86°C | |
| 硬度 (Shore D) | 93-96 | |

| 放氣量 CVCM | 0.01% | |

**為何選擇它？**

- 雖然 CTE (35 ppm/°C) 不是最佳匹配，但綜合性能最優
- 氧化鋁填料在極低溫下扮演「釘扎」角色，阻止裂紋擴展，維持殘餘韌性
- 熱導率高，有助於量子位元的熱錨定

### 替代方案

| 膠材 | CTE | 熱導率 | 優點 | 缺點 |
|------|-----|-----|----------|--------|

| **聚酰亞胺基膠材** | 15-25 ppm/°C | 0.3-0.5 W/m·K | 與 Kapton 化學相容性最佳 | 熱導率低，需調整 CTE |

## 三、脆化機制與對策 為何在 15mK 會**脆化**？

1. **玻璃態轉變**：環氧樹脂 Tg ≈ 86°C，在極低溫下分子鏈段完全凍結，衝擊韌性下降 **90% 以上**
2. **熱活化抑制**：15mK 對應熱能 kT ≈ 1.3×10⁻²⁴ J，遠低於分子運動活化能 (~10⁻¹⁹ J)，裂紋擴展無法透過塑性變形緩解
3. **蠕變失效**：殘留應力無法透過蠕變釋放，循環疲勞累積

### 脆化量化數據

| 材料 | 室溫衝擊強度 | 4K 衝擊強度 | 脆化比率 |
|------|------------|------------|---------|
| 純環氧樹脂 | 15-25 kJ/m² | 2-5 kJ/m² | 75-85% |
| **Stycast 2850FT** | 8-12 kJ/m² | **3-6 kJ/m²** | **50-60%** |
| CTBN 改質環氧 | 25-40 kJ/m² | 8-15 kJ/m² | 60-70% |

**關鍵**：氧化鋁填料使 Stycast 2850FT 的脆化程度低於純環氧。

### 防止脆化策略

| 策略 | 具體措施 |
|------|---------|
| **材料** | 選用韌性改質環氧 (CTBN、核殼增韌劑) |
| **幾何** | 膠層厚度 **<< 30μm**，圓弧過渡 (R > 2mm)，應力釋放槽 |
| **製程** | 分段固化、緩慢降溫 (≤1°C/min)、預調適熱循環 |

## 四、詳細製程流程（13 步驟）

```
步驟 1: 材料檢驗與儲存
   └─ RO4350B 確認厚度公差 ±5%，Kapton 選用 HN/VN 型 25-50μm
   └─ 儲存：18-25°C，RH < 60%

步驟 2: RO4350B 表面處理 ⭐關鍵
   ├─ 微蝕刻 (Microetching)，粗糙度 Ra 0.3-0.8μm
   ├─ 等離子清洗：O₂/N₂ 混合氣體，功率 300W，10 分鐘
   └─ 立即進入無塵室 (< 30 分鐘內塗膠)

步驟 3: Kapton 表面處理 ⭐關鍵
   ├─ 電暈處理 (Corona, 2-3 passes) 或鹼處理 (NaOH 10%, 70°C, 10min)
   ├─ 徹底水洗 + 乾燥
   ├─ 塗佈矽烷偶聯劑 (γ-GPS, 1-2% in ethanol)
   └─ 烘烤 120°C, 30min 去除溶劑

步驟 4: 膠材調製
   ├─ 精確稱量：Stycast 2850FT : Catalyst 9 = 100 : 4 (重量比)
   ├─ 真空脫泡攪拌：300rpm，10 分鐘
   └─ 真空脫泡：1-5 mmHg，3-10 分鐘至氣泡消除

步驟 5: 塗佈
   ├─ 刮刀塗佈或網版印刷
   └─ 目標厚度：**25-50μm**，均勻性 ±5μm

步驟 6: 貼合對位
   └─ CCD 對位系統，精度 ±0.05mm

步驟 7: 壓合
   └─ 壓力 0.5-1.0 MPa，室溫，30 分鐘

步驟 8: 初固化
   └─ 25°C，16-24 小時 (或 35°C，8-12 小時加速)

步驟 9: 後固化 ⭐關鍵
   ├─ 65-80°C，2-4 小時
   ├─ 目的：提高交聯密度，降低殘留應力
   └─ 建議 DSC 驗證，Tg 偏移 < 2°C

步驟 10: 緩慢降溫
   └─ ≤ 1°C/分鐘 至室溫，避免熱衝擊

步驟 11: 品質檢驗
   ├─ C-scan 超音波：確認無脫層、氣泡
   ├─ 切片分析：膠層厚度、界面附著
   └─ 附著力測試：90° 剝離 > 5 N/mm

步驟 12: 熱循環預調適
   └─ 300K ↔ 77K (液氮)，5 次循環，檢查分層/裂紋

步驟 13: 除氣處理
   ├─ 100°C，24 小時，真空 < 10⁻³ Pa
   └─ 目的：徹底除氣，避免稀釋製冷機中放氣
```

## 五、關鍵製程參數控制

| 參數 | 建議值 | 容差 | 備註 |
|------|--------|------|------|
| **膠層厚度** | **25 μm** | ±5 μm | 最關鍵！每增 10μm，應力增 ~30% |
| 固化溫度 (初固) | 25°C | ±2°C | |
| 後固化溫度 | 80°C | ±2°C | 高於最高使用溫度 |
| 後固化時間 | 4h | - | 殘留應力 ↓ 30% |
| 降溫速率 | ≤ 1°C/min | - | 熱衝擊控制 |
| 等離子處理功率 | 300W | - | 表面能 ↑ 40% |
| 矽烷偶聯劑濃度 | 2% | - | 附著力 ↑ 25% |

| 測試項目 | 條件 | 合格標準 |

## 七、設計建議

1. **避免大面積 Z 向約束**：RO4350B Z 軸收縮 (0.73%) 遠大於 Kapton (0.40%)，設計柔性過渡區吸收應變
2. **熱過孔設計**：膠層熱導率 1.25 W/m·K 不足以快速導熱，建議銅質熱過孔 (直徑 0.3mm，間距 2mm) 填充導熱膠
3. **微波損耗**：Stycast 2850FT 室溫 tan δ ≈ 0.003，低溫下通常降低 50%，對 4-8 GHz 量子位元操作影響可控
