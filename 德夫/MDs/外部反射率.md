# 外部反射率 (Outside Reflectance) 在鳥類防撞設計中的應用情境

## 📚 關于 Klem, D., Jr. (2009) 論文背景

Klem 的研究指出，**鳥類撞擊窗戶是人類活動導致鳥類死亡的第二大原因**，僅次于家貓捕食。該研究強調玻璃的**反射性**(reflective)與**透明性**(transparent)是造成鳥類誤判的兩大關鍵因素 [[4]][[7]]。

---

## 🔍 外部反射率 (Outside Reflectance) 的定義

**外部反射率**指的是建築玻璃外表面（Surface #1 / Face 1）對入射光線的反射能力，通常以百分比表示。在鳥類防撞設計中，這一參數具有以下技術含義：

| 參數 | 說明 |
|------|------|
| **測量標準** | 通常依據 ASTM E903 或 ASTM C1549 等標準測量太陽能反射率 |
| **關鍵阈值** | 外部反射率 **≤15%** 被視爲"低反射玻璃"，可降低鳥類誤判風險 [[38]][[46]] |
| **測量位置** | 必須在玻璃**外表面**（朝向鳥類的一側）測量，因鳥類從外部觀察玻璃 |

---

## 🦅 應用情境與鳥類視覺機制

### 1️⃣ 反射造成的"栖息地錯覺"
- 當玻璃外部反射率較高時，會鏡像反射天空、樹木或植被
- 鳥類無法識別這是反射影像，會試圖飛向"看到的栖息地"而撞擊玻璃 [[14]][[33]]
- **應用建議**：在反射率>15%的玻璃區域，必須附加視覺標記（如陶瓷釉點、酸蝕圖案）

### 2️⃣ 與視覺標記的協同設計
根據 Klem 提出的 **"2×4 規則"**（水平間距≤2英寸/5cm，垂直間距≤4英寸/10cm）[[45]]：

```
✅ 有效組合：
• 低反射玻璃 (≤15% outside reflectance) + 視覺標記 → 最佳效果
• 高反射玻璃 + 密集視覺標記（應用于外表面）→ 可接受方案
• 僅靠低反射玻璃無標記 → 仍可能造成"通道效應"(passage effect)，不推薦單獨使用
```

### 3️⃣ UV反射率的特殊應用
- 鳥類可感知 300-400nm 紫外光譜，人類不可見
- UV反射標記需達到 **20-40% 反射強度**（300-400nm波段），并與高UV吸收區域交替排列，間距遵循2×4規則 [[45]]
- 此類設計可在保持建築美學透明度的同時，向鳥類提供可見警示

---

## 🏗️ 建築規範中的實際應用

### 紐約市地方立法 15號 (Local Law 15)
- 要求75英尺以下外牆玻璃使用"鳥類友好材料"（威脅因子 TF ≤25）[[46]]
- **低反射不透明材料**定義：具有反射或低輻射塗層，且**外部反射率≤15%** 的玻璃 [[46]]

### 多倫多綠色建築標準 (Toronto Green Standard)
- 明確將"外部反射率≤15%"作爲合規策略之一 [[38]][[45]]
- 若使用反射率>15%的夾層玻璃（spandrel glass），必須配合視覺標記使用

---

## ⚠️ 重要注意事項

1. **測量表面至關重要**：標記必須應用于玻璃外表面（Surface #1），內表面應用會因反射干擾而失效 [[14]][[45]]

2. **反射率非唯一指標**：即使低反射玻璃，若無視覺標記，在特定光照角度下仍可能產生危險反射或"黑洞效應"[[42]]

3. **現場驗證必要性**：隧道實驗（tunnel test）結果可能與實地場測（field test）存在差異，Klem 強調**實地測試是驗證防撞效果的最終標準**[[45]]

4. **動態光照影響**：外部反射率會隨時間、天氣、觀察角度變化，設計時需考慮最不利工況 [[8]][[42]]

---

## 🔧 實用設計建議

```
📐 玻璃選型優先級：
1. 優先減少玻璃總面積（窗牆比<40%）
2. 選擇外部反射率≤15%的低反射玻璃
3. 在外表面應用符合2×4規則的高對比度視覺標記
4. 避免使用鏡面玻璃（mirrored glass），其爲最高風險類型
5. 對于必須使用的高反射區域，采用密集圖案或外置遮陽構件打斷反射

🔧 既有建築改造：
• 外貼鳥類友好薄膜（如Feather Friendly®點狀圖案）
• 安裝外部遮陽網、百葉或格栅
• 使用外部塗料繪制高對比度圖案（間距≤10×10cm）
```

> 📌 **核心結論**：外部反射率是評估玻璃鳥類撞擊風險的重要光學參數，但**不能單獨作爲安全判定依據**。有效的鳥類友好設計需結合"低反射率 + 表面視覺標記 + 合理建築形態"的系統性策略，并優先在玻璃外表面實施干預措施。

如需進一步了解特定玻璃產品的威脅因子(Threat Factor)或合規測試協議，建議參考美國鳥類保護協會(ABC)的威脅因子數據庫或正在制定中的 ASTM 鳥類防撞材料標準 [[40]][[46]]。
