## 一、Hammerstad-Jensen 模型在低溫量子傳輸線的適用性

### 1. 模型適用性分析

| 模型假設 | 低溫量子傳輸線現實 | 有效性評估 |
|---------|------------------|-----------|
| **TEM/quasi-TEM 傳播模式** | w/h < 10 時成立 | ✅ **有效** |
| **介電常數 εr 為常數** | εr 在 4K 下降 5-10% | ⚠️ **需修正** |
| **無損耗介電質** | tanδ ≈ 0.002 | ✅ **對 Z0 影響可忽略** |
| **完美導體** | 表面電阻 Rs 有限 | ⚠️ **需使用表面阻抗** |
| **各向同性基板** | Kapton 些微異向性 | ✅ **影響輕微** |
| **室溫尺寸** | 熱收縮導致尺寸變化 | ⚠️ **需熱膨脹修正** |

### 2. 低溫修正公式

**介電常數溫度修正：**
$$\varepsilon_{r,eff}(T) = \varepsilon_r(300K) \times [1 - 0.08 \times (1 - \frac{T}{300})]$$

**熱收縮尺寸修正：**
$$L(T) = L_0 \times [1 - \alpha \cdot (300 - T)]$$
其中 α = 20 μm/m·K (Kapton)

**表面阻抗修正（非超導態）：**
$$Z_s = \sqrt{\frac{j\omega\mu}{\sigma}} = \sqrt{\frac{\omega\mu}{2\sigma}}(1+j)$$

### 3. 為何 H-J 模型仍適用？

```
關鍵原因：
1. 準 TEM 模式在低頻（<20 GHz）依然主導
2. 微帶線色散效應在量子位元頻段（4-8 GHz）輕微
3. 有效介電常數變化 < 3%，對 Z0 影響 < 1.5%
4. 超導態時 Rs → 0，模型誤差進一步降低
```

**頻率色散效應（Kirschning-Jansen 修正）：**
$$\varepsilon_{eff}(f) = \varepsilon_r - \frac{\varepsilon_r - \varepsilon_{eff}(0)}{1 + P_1 P_2}$$

在 6 GHz 時，εeff 僅比靜態值高約 1.2%，對 50Ω 設計影響可忽略。

## 二、高密度佈局的串擾抑制策略

### 1. 串擾機制分析

**近場串擾（主導，s < λ/20）：**

- **電容耦合 (Cm)**：電場耦合，與間距成反比
- **電感耦合 (Lm)**：磁場耦合，與迴路面積相關

**遠場串擾（s > λ/20）：**
- 輻射場耦合，以 1/r 衰減

**Cri/oFlex 現況：**

- @ 6 GHz，λ ≈ 50 mm（在 Kapton 中）
- 間距 s = 1 mm → s/λ = 0.02 << 0.05
- **完全處於近場區域**，需控制 Cm 與 Lm

### 2. 耦合係數計算

**簡化耦合係數公式：**
$$k \approx 0.5 \left(\frac{w/h}{w/h + s/h}\right)^{1.5}$$

**Cri/oFlex 參數：**

- w = 100 μm, h = 50 μm → w/h = 2
- s = 1 mm, h = 50 μm → s/h = 20
- **k ≈ 0.01 (-40 dB)**

### 3. Scale-Up 至 1000+ 量子位元的抑制技術

| 技術 | 實現方式 | 改善幅度 | 應用於 Cri/oFlex |
|------|---------|---------|----------------|
| **1. 超導屏蔽層** | 250 nm Nb 薄膜於外層 | -20 to -40 dB | ✅ 已採用 |
| **2. 差分信號傳輸** | CPS (Coplanar Stripline) 架構 | -30 to -50 dB | ⚠️ 可升級 |
| **3. 3D 立體堆疊** | 多層柔性電路 + TSV | -25 dB | 🆕 發展中 |
| **4. 頻率分離佈局** | 棋盤式高低頻交錯 | -20 to -30 dB | ✅ 已採用 |
| **5. 接地護環** | 浮動電位屏障 | -15 to -25 dB | ⚠️ 可選配 |
| **6. 吸收材料** | 損耗性介電塗層 | -10 to -15 dB | 🆕 研究中 |

### 4. 具體優化方案

#### 方案 A：Stripline 升級（立即實施）
```
結構：GND | Signal | Dielectric | Signal | GND
      3μm    5μm      25μm        5μm     3μm

優勢：
- 電場完全侷限於介電層內
- 串擾降低至 -60 dB (s = 0.5 mm)
- 保持柔性，厚度僅增加 20%
```

#### 方案 B：3D 多層整合（中期目標）
```
Layer 1: Signal (256 ch) ──┐
Layer 2: Nb Ground Shield  │ TSV 垂直互連
Layer 3: Signal (256 ch) ──┤
Layer 4: Nb Ground Shield  │
Layer 5: Signal (256 ch) ──┤
Layer 6: Nb Ground Shield  │
Layer 7: Signal (256 ch) ──┘

總計：1024 通道，佔地面積不變
串擾：層間 -80 dB，層內 -40 dB
```

#### 方案 C：差分信號架構（長期規劃）
```
傳統單端：S/G/S/G/S/G (串擾 -40 dB)
差分架構：D+/D-/G/D+/D- (串擾 -60 dB)

D+ 與 D- 緊密耦合，外部場相互抵消
需配套差分驅動電路與平衡-不平衡轉換器
```

### 5. 關鍵設計準則

**幾何準則：**

- **s/h > 3**：確保基本隔離度 > -30 dB
- **w/h ≈ 2**：特性阻抗 50Ω 的最佳化比例
- **避免平行長度 > λ/4**：減少諧振耦合

**材料準則：**

- **屏蔽層**：Nb (Tc=9.2K) 或 NbTi (Tc=9.2K, Bc2=14.5T)
- **低介電常數**：尋找 εr < 2.5 的低溫穩定材料
- **低損耗**：tanδ < 0.001 @ 6 GHz

**佈局準則：**

- **正交佈線**：相鄰層信號線垂直走向
- **頻率分離**：相鄰通道頻差 > 100 MHz
- **分段屏蔽**：每 λ/10 長度設置接地過孔
