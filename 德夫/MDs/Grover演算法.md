### 1. 狀態向量視覺化 (State Vector)

- 將 $N$ 個可能的狀態表示為 $N$ 維向量
- 每個分量是**複數振幅**（可正可負，甚至虛數）
- 機率 = 振幅的模平方 $|\alpha|^2$

```
初始狀態：所有振幅相等（均勻疊加）
┌─────────────────────────────┐
│ 1/√N  1/√N  1/√N  ...  1/√N │  ← 每個都是小振幅
└─────────────────────────────┘
         ↓ 經過 Grover 迭代
┌─────────────────────────────┐
│  0    0   0.99  ...   0     │  ← 目標答案振幅被放大
└─────────────────────────────┘
```

### 2. Grover 演算法的「反轉與擴散」
這是影片最精華的動畫部分：

**步驟一：Oracle 反轉 (Inversion about the answer)**
- 將目標答案的振幅**反轉**（乘以 -1）
- 視覺上像是以平均值為軸的鏡射

**步驟二：擴散操作 (Diffusion / Inversion about the mean)**
- 將所有振幅關於**平均值**再次反轉
- 結果：正確答案的振幅被放大，其他被壓縮

```
振幅變化示意（2D 簡化）：

初始：   Oracle後：  擴散後：
  ↑        ↑          ↑
  │    ┐   │    ┐     │  ┌──┐  ← 目標振幅放大
  ├────┤   ├─-──┤     ├──┤  │
  │    │   │    │     │  └──┘
  └────┘   └────┘     └──────
所有相等  目標反轉   目標變大，其他變小
```

### 3. 幾何解釋
影片用**二維平面**優雅地展示：
- 一個軸代表「正確答案子空間」
- 另一個軸代表「錯誤答案子空間」
- 每次迭代相當於旋轉一個固定角度
- 經過約 $\frac{\pi}{4}\sqrt{N}$ 次迭代後，狀態幾乎對齊正確答案

```
        正確答案軸
            ↑
            │    /  狀態向量
            │   /
            │  /  ← 每次迭代旋轉角度 θ ≈ 2/√N
            │ /
            │/________→ 錯誤答案軸
           /
          /
    初始狀態（45度方向）
```
