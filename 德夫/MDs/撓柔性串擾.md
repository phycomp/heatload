## 📐 串擾理論模型 (FEXT/NEXT)

### 基本耦合係數公式 [[79]][[81]]

對於平行耦合傳輸線，串擾可由 **互電容 $C_m$** 與 **互電感 $L_m$** 計算：

```
近端串擾 (NEXT) 電壓：
  V_NEXT(t) = K_b · [V_aggressor(t) - V_aggressor(t-2·T_D)]

遠端串擾 (FEXT) 電壓：
  V_FEXT(t) = K_f · L · dV_aggressor(t-T_D)/dt

其中：
  K_b = ¼·(C_m/C + L_m/L)          # 反向耦合係數 (NEXT)
  K_f = ½·(C_m/C - L_m/L)·v_p      # 正向耦合係數 (FEXT)
  
  C, L  = 單位長度自電容/自電感
  C_m, L_m = 單位長度互電容/互電感
  v_p = 1/√(LC) = 訊號傳播速度
  T_D = L/v_p = 傳輸延遲
```

### 低溫修正因子 (20mK)

在毫開爾文溫度下，需考慮 [[1]][[21]]：

1. **導體損耗降低**：銀導體電阻率隨溫度下降，$R \propto T^{5}$ (低溫極限)
2. **介電損耗變化**：Polyimide 的 $\tan\delta$ 在 20mK 可低至 $2.2×10^{-5}$ [[1]]
3. **熱噪聲抑制**：$V_{noise} = \sqrt{4k_BTRB}$，20mK 時熱噪聲極低

## 🔑 關鍵設計要點

1. **低溫參數校正**：20mK 下銀導體電阻率極低，需手動輸入測量值 [[1]]
2. **耦合係數模型**：採用指數衰減近似 $k \propto e^{-\pi s/2h}$ 估算互參數
3. **頻域掃描**：支援 0.1-26 GHz 全頻段分析，符合 Cri/oFlex 工作範圍 [[10]]
4. **規格比對**：自動標示 -60 dB 隔離度規格線，快速評估設計餘裕
5. **模組化架構**：可擴充加入量子位元耦合、熱負載計算等模組

## ⚠️ 注意事項

| 項目 | 說明 |
|------|------|
| **模型限制** | 簡化傳輸線理論，未考慮高階模態與輻射耦合 |
| **低溫校準** | 建議以實測 $S_{31}$ (NEXT) / $S_{41}$ (FEXT) 校正模型參數 [[86]] |
| **量子系統整合** | 串擾可能導致量子位元頻率漂移，需配合量子錯誤校正評估 [[76]][[77]] |
| **熱設計** | 20mK 階段熱負載需 <20 nW，佈線長度與數量需嚴格控制 [[10]] |

如需進一步整合 **量子錯誤校正資源估算** 或 **多通道同步時序分析**，我可協助擴充此模擬器架構。
