## 論文摘要：《互連運作原理：導體損耗與色散建模》

### 研究背景與挑戰

```
┌─────────────────────────────────────────┐
│高速串列資料通道需求：10-100 Gbps        │
│需要準確覆蓋 5-6 個頻率數量級的傳輸線模型│
│主要障礙：                               │
│  ① 損耗性與色散材料                     │
│  ② PCB/封裝製造過程中的互連局部化破壞   │
└─────────────────────────────────────────┘
```

### 核心物理機制：趨膚效應（Skin Effect）

```
頻率由低到高的電流分布演變：

DC/低頻 t ≤ 0.5δ    中頻 (過渡區)     高頻 (t ≥ 5δ)
┌──────────────┐   ┌─────────────┐   ┌─────────────┐
│ ████████████ │   │    ████     │   │    ▓▓▓▓     │
│ ████████████ │ → │  ████████   │ → │   ▓▓▓▓▓▓    │
│ ████████████ │   │    ████     │   │    ▓▓▓▓     │
│ 均勻分布     │   │  電流擁擠   │   │  表面薄層   │
│              │   │  邊緣效應   │   │  (趨膚效應) │
└──────────────┘   └─────────────┘   └─────────────┘

δ = 趨膚深度 = 1/√(πfμσ)
```



### 關鍵發現：導體內部的能量流動

```
訊號傳輸誤解 vs 實際物理：

錯誤認知：電流在導體內沿訊號方向流動傳輸能量
                    ↓
實際物理：
┌──────────────────────────────────┐
│介電質區域 (能量傳輸主要區域)     │
│─────────────────────────────→    │  Poynting 向量
│         訊號傳播方向             │
│┌────┐              ┌────┐        │
││導體│              │導體│        │
││表面│ ←←←←←←←←←←←  │內部│        │
││    │   能量流入   │    │        │
│└────┘   (被吸收)   └────┘        │
│                                  │
│導體內部電流實際垂直於表面向內流動│
│在約 2δ 深度處電流方向甚至會反轉  │
└──────────────────────────────────┘
```



### 導體表面粗糙度效應

```
粗糙表面增加損耗的機制：

平滑表面           粗糙表面
┌────────┐       ┌──┬──┬──┐
│        │       │  │  │  │
│        │  vs   └──┴──┴──┘
│        │       表面積增加 2-3 倍
└────────┘       → 能量吸收增加 50% 以上

粗糙度必須考慮的條件：rms 粗糙度 ≈ 0.5-1 × 趨膚深度
```

### 超越趨膚效應：Drude 模型

```

      │                        │
      │    δ ∝ 1/√f            │    δ 趨於飽和
      │    持續減小            │    │
    δ │         ↘              │    ├────────→
      │           ↘            │    │
      │             ↘          │    │

      THz                        THz  紅外線  可見光

關鍵結果：奈米級互連在光頻段仍無趨膚效應！
```



### 結論：100 Gbps 設計的三大要求

```
┌──────────────────────────────────────────────────┐
│1. 準確提取單位長度參數 (p.u.l.) 與模態傳輸線參數 │
│   → 條帶線用準靜態場求解器，微帶線用 3D 全波分析 │
│2. 導體內部模型必須在 5-6 個頻率數量級上有效且因果│
│   → 考慮電流擁擠、鄰近效應與邊緣效應             │
│3. 導體表面粗糙度建模至少需兩參數模型             │
│   → Modified Hammerstad 或 Huray 雪球模型        │
│最終目標：模型必須在訊號頻譜範圍內通過測量驗證    │
└──────────────────────────────────────────────────┘
```
