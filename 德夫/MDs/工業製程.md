## 一、Cri/oFlex 3 多層 Stack-up 結構

### 核心架構：Ground-Signal-Ground（GSG）帶狀線

Cri/oFlex 3 採用 **屏蔽帶狀線（Shielded Stripline）** 結構，其多層 Stack-up 如下 ：

```
┌─────────────────────────────────────────┐
│  上屏蔽層（Top Ground Plane）           │
│  ───── Ag 或 NbTi 數μm ─────── ←PVD濺鍍 │
├─────────────────────────────────────────┤
│  上介電層（Upper Dielectric）           │
│ ───── Polyimide聚醯亞胺───── ←壓合/旋塗 │
├─────────────────────────────────────────┤
│  中心導體層（Center Conductor）         │
│  ├── 8 條獨立訊號線（各 50 Ω）          │
│  │   線寬/線距：數百 μm 級              │
│  │   材料：Ag 或 NbTi(數μm) ←PVD+光刻   │
│  └── 整合被動元件：                     │
│      • 衰減器（TaN 電阻膜）             │
│      • 低通濾波器（階梯阻抗結構）       │
│      • 紅外線濾波器（懸浮金屬粉末）     │
├─────────────────────────────────────────┤
│  下介電層（Lower Dielectric）           │
│  ───── Polyimide（聚醯亞胺）──────────  │
├─────────────────────────────────────────┤
│  下屏蔽層（Bottom Ground Plane）        │
│  ───── Ag 或 NbTi（數 μm）── ←PVD濺鍍── │
└─────────────────────────────────────────┘

總厚度：0.3 mm（300 μm）
通道數：8 通道/條
通道間距：2 mm
```

### 與傳統 Microstrip 的結構差異

| 特性 | Cri/oFlex 3 Stripline | 傳統 Microstrip |
|------|----------------------|----------------|
| **屏蔽效果** | 上下雙接地層，電磁場完全封閉 | 單面接地，輻射損耗大 |
| **串擾抑制** | -40 dB（通道間） | 通常 > -20 dB |
| **彎曲影響** | 對阻抗影響小 | 彎曲時阻抗變化大 |
| **製程複雜度** | 多層對位、壓合 | 單面製程較簡單 |

## 二、工業級 PVD 製程實現

### 2.1 製程平台選擇：Roll-to-Roll vs. Sheet-to-Sheet

根據工業級柔性電路製造技術 ，Cri/oFlex 3 的 PVD 製程可採用兩種平台：

| 平台 | 適用規模 | 優勢 | 挑戰 |
|-----|---------|-------|-------|
| **Roll-to-Roll R2R** | 大規模量產（>1000 條/批次） | 連續生產、長度不受限、單位成本低  | 設備投資高、張力控制難 |
| **Sheet 2 Sheet** | 中小批量、客製化 | 對位精度高、適合多層壓合 | 生產效率較低 |

**Delft Circuits 現況**：目前採用 S2S 批次製程，在 1000 m² 試產設施中進行 ；未來擴展至 32 通道時可能導入 R2R。

### 2.2 PVD 製程流程詳解

#### Step 1：基板準備與電漿前處理（Plasma Pre-treatment）

```
聚醯亞胺薄膜輸入
    ▼
┌─────────────────┐
│ 電漿清潔區段    │← O₂ 或 Ar 電漿
│ • 去除表面污染物│
│ • 增加表面能    │→ 接觸角 < 30°
│ • 產生懸掛鍵    │→ 提升金屬附著性
└─────────────────┘
    ▼
┌─────────────────┐
│ 逆濺射蝕刻（可選│← Ar⁺ 轟擊
│ • 去除氧化層    │
│ • 微粗糙化表面  │→ 機械鎖合效應
└─────────────────┘
```

**關鍵參數**：

- **氣體選擇**：O₂ 電漿用於有機污染物去除；Ar 電漿用於物理清潔
- **處理劑量（Dose）**：需控制在 Zone B（最佳附著區），避免過度處理導致基板損傷
- **溫度控制**：聚醯亞胺耐溫上限約 200°C，需冷卻滾輪輔助

#### Step 2：金屬層 PVD 沉積

**A. 銀（Ag）版本製程**

| 製程參數 | 規格 |
|----------|------|
| **PVD 方法** | DC 磁控濺鍍（DC Magnetron Sputtering） |
| **靶材** | 高純度 Ag 靶（>99.99%） |
| **濺鍍功率** | 5–15 kW（依靶材尺寸） |
| **沉積速率** | 50–200 nm/min |
| **基板溫度** | < 150°C（低溫製程） |
| **膜厚** | 3–10 μm（接地層）；5–15 μm（中心導體） |
| **附著層** | Cr 或 Ti（10–50 nm） |

**附著層必要性**：

- Ag 與 Polyimide 直接附著性差，易剝離
- 插入 **Cr 或 Ti 附著促進層**（Adhesion Layer）可提升結合強度 3–5 倍

```
Ag 沉積 Stack-up
┌─────────────────┐
│  Ag（3–10 μm）  │← 主導體層
├─────────────────┤
│  Cr 或 Ti 20 nm │← 附著促進層
├─────────────────┤
│  Polyimide      │← 基板
└─────────────────┘
```

**B. NbTi 超導版本製程**

| 製程參數 | 規格 |
|----------|------|
| **PVD 方法** | DC 或 RF 磁控濺鍍 |
| **靶材** | NbTi 合金靶（比例 47:53 或 44:56） |
| **沉積速率** | 0.4–2 nm/s  |
| **基板溫度** | 室溫至 200°C |
| **膜厚** | 3–8 μm |
| **臨界溫度（Tc）** | > 9 K（需後熱處理優化） |

**超導薄膜關鍵控制**：

- **應力控制**：微壓縮應力（slightly compressive）避免剝離
- **均勻性**：大面積濺鍍需旋轉靶材（Rotatable Cathode）

#### Step 3：光刻圖案化（Photolithography）

```
金屬化基板輸入
    ▼
┌─────────────────┐
│ 光阻塗佈        │← 乾膜光阻（Dry Film）或液態光阻
│ • 厚度10–50 μm  │→ 依蝕刻深度選擇
│ • 軟烤80–100°C  │
└─────────────────┘
    ▼
┌────────────────────┐
│ 曝光Exposure       │← i-line（365 nm）或 DUV
│ • 劑量100–500mJ/cm²│
│ • 對位精度±5 μm    │
└────────────────────┘
    ▼
┌─────────────────┐
│ 顯影Development │← 鹼性顯影液TMAH 系
│ • 時間30–120sec │
│ • 線寬控制±2 μm │
└─────────────────┘
    ▼
┌─────────────────┐
│ 硬烤 Hard Bake  │← 120–150°C
│ •增強光阻耐蝕性 │
└─────────────────┘
```

#### Step 4：濕式化學蝕刻（Wet Etching）

| 材料 | 蝕刻液 | 特性 |
|------|--------|------|
| **Ag** | HNO₃:H₂O 或 Fe(NO₃)₃ 系 | 快速、選擇性高 |
| **Cr/Ti 附著層** | 過硫酸銨（APS）或 HF 系 | 不傷害 Polyimide |
| **NbTi** | HF:HNO₃ 混合酸 | 需控制側蝕（Undercut） |

**蝕刻控制要點**：
- **側蝕抑制**：過度側蝕會導致線寬縮減、阻抗偏差
- **蝕刻均勻性**：噴淋式（Spray）優於浸泡式（Dip）

#### Step 5：多層疊合與壓合（Lamination）

```
第一層結構（下接地層 + 介電層）
    ▼
┌───────────────────┐
│ 第二層介電層壓合  │← 熱壓或膠合
│ • 溫度：180–200°C │
│ • 壓力：1–5 MPa   │
│ • 時間：30–60 min │
│ • 無膠Adhesiveless│→ 避免低溫脫層
└───────────────────┘
    ▼
中心導體層製作 重複Step2–4
    ▼
┌─────────────────┐
│ 上介電層壓合    │
└─────────────────┘
    ▼
上接地層製作（重複 Step 2–4）
```

**關鍵挑戰：無膠多層結構（Adhesiveless）**
- 傳統丙烯酸粘合劑在極低溫下收縮係數不匹配，導致分層
- 解決方案：直接將金屬濺鍍於 Polyimide 表面，或以熱塑性 Polyimide 作為粘合層

#### Step 6：通孔與連接（Via Formation）

| 方法 | 應用 | 參數 |
|------|------|------|
| **雷射鑽孔** | 上下接地層互連 | UV 或 CO₂ 雷射，孔徑 50–200 μm |
| **化學蝕刻開窗** | 元件暴露區域 | O₂ 電漿或濕蝕刻 |
| **機械沖孔** | 連接器安裝孔 | 精密模具沖壓 |

#### Step 7：被動元件整合製程

**A. 薄膜衰減器（Thin-Film Attenuator）**

```
製程流程：
┌─────────────────────┐
│ TaN 或 NiCr 濺鍍    │← 電阻材料
│ • 膜厚 10–100 nm    │
│ • 方阻Rs 10–500 Ω/□ │
└─────────────────────┘
    ▼
┌─────────────────┐
│ 光刻圖案化      │→ 定義電阻幾何形狀
└─────────────────┘
    ▼
┌─────────────────┐
│ 蝕刻成形        │→ 多個 5 dB 單元串聯
└─────────────────┘
```

**B. 低通濾波器（Low-Pass Filter）**

| 結構 | 製程方法 | 功能 |
|----|-------|----|
| **階梯阻抗型** | 與中心導體同時光刻 | 寬金屬區=電容;窄金屬線=電感 |
| **集總元件型** | 額外濺鍍 + 光刻 | 獨立 L、C 元件組合 |

**C. 紅外線濾波器（IR Filter）**

- 將 **懸浮金屬粉末**（如 Cu、Ag 微粒）嵌入 Polyimide 介電層中
- 增加微波頻段損耗，阻擋紅外線熱輻射進入量子位元

## 三、工業級 PVD 設備規格

### 建議設備配置（參考工業標準 ）

| 模組 | 規格 | 功能 |
|------|------|------|
| **進料腔（Load Lock）** | 真空度 < 10⁻³ mbar | 避免大氣污染 |
| **電漿前處理腔** | O₂/Ar 電漿源，功率 1–5 kW | 表面活化、清潔 |
| **濺鍍腔 1（接地層）** | DC 磁控濺鍍，2 組旋轉靶 | Ag 或 NbTi 沉積 |
| **濺鍍腔 2（附著層）** | DC 濺鍍，1 組平面靶 | Cr/Ti 附著促進層 |
| **中間轉換腔** | 真空傳輸，不破真空 | 多腔連續製程 |
| **光刻單元（可選 inline）** | i-line 曝光機 | 圖案化 |
| **蝕刻單元（可選 inline）** | 噴淋式蝕刻槽 | 金屬圖案化 |
| **出料腔（Exit Lock）** | 氮氣回充 | 保護薄膜表面 |

### 關鍵製程控制參數

| 參數 | 控制目標 | 監測方法 |
|------|---------|---------|
| **膜厚均勻性** | ±5%（6σ） | 原位椭偏儀（In-situ Ellipsometer） |
| **應力控制** | 微壓縮（< -100 MPa） | 基板曲率法（Wafer Curvature） |
| **附著強度** | > 5B（ASTM D3359） | 百格刀測試（Cross-cut Test） |
| **表面粗糙度** | Ra < 10 nm | AFM 或白光干涉儀 |
| **臨界溫度（NbTi）** | Tc > 9 K | 四點探針 + 低溫腔 |

## 四、製程挑戰與解決方案

### 挑戰 1：Polyimide 與金屬的熱膨脹係數（CTE）不匹配

| 材料 | CTE（ppm/K） |
|------|-------------|
| Polyimide | 20–50 |
| Ag | 19 |
| NbTi | 8–10 |

**問題**：溫度循環（300 K → 10 mK）導致熱應力，引發剝離或裂紋。

**解決方案**：
1. **緩衝層設計**：插入 CTE 過渡層（如 Ti，CTE ~8.6 ppm/K）
2. **膜厚優化**：金屬層厚度 < 10 μm，降低總應力
3. **低溫退火**：沉積後於 150°C 退火，釋放殘留應力

### 挑戰 2：低溫 PVD 的薄膜品質

傳統 PVD 需 200–500°C 才能獲得緻密薄膜 ，但 Polyimide 耐溫上限約 200°C。

**解決方案**：

- **高功率脈衝磁控濺鍍（HiPIMS）**：提升離化率，低溫下獲得緻密薄膜
- **離子輔助沉積（IAD）**：以低能量離子轟擊，增強表面遷移
- **基板偏壓**：-50 至 -200 V，提升附著與緻密度

### 挑戰 3：多層對位精度

Cri/oFlex 3 的 8 通道需上下層精確對位，否則阻抗偏差。

**解決方案**：

- **自動光學對位（AOI）**：每層曝光前對準標記（Alignment Mark）
- **補償設計**：預留收縮補償值（通常 0.1–0.3%）

## 五、總結：Cri/oFlex 3 工業級 PVD 製程藍圖

```
          Cri/oFlex 3 工業級 PVD 製程
   1. 聚醯亞胺基板準備（< 100 μm/層）
      → 電漿清潔 + 逆濺射活化
   2. 附著促進層 PVD（Cr/Ti，20–50 nm）
      → DC 磁控濺鍍，低溫製程
   3. 主導體層 PVD（Ag 或 NbTi，3–10 μm）
      → DC/RF 磁控濺鍍，原位膜厚監控
   4. 光刻圖案化（i-line，線寬數百 μm）
      → 乾膜光阻，噴淋顯影
   5. 濕式蝕刻 + 剝離
      → 選擇性蝕刻液，控制側蝕
   6. 介電層壓合（無膠熱壓，180–200°C）
      → 第二層 Polyimide 疊合
   7. 重複步驟 2–5（中心導體層）
      → 整合 TaN 衰減器、濾波器結構
   8. 重複步驟 6–7（上介電層 + 上接地層）
   9. 雷射通孔 + 連接器安裝
   10. 電性測試 + 低溫驗證（4K/mK）
       → S 參數、直流電阻、臨界電流
```

**核心成功因素**：

1. **低溫 PVD 技術**：< 150°C 下獲得高品質金屬薄膜
2. **附著促進層**：Cr/Ti 界面層解決 Polyimide-金屬附著問題
3. **無膠多層結構**：避免極低溫下的熱應力分層
4. **原位監控**：椭偏儀即時反饋膜厚與光學常數

此製程架構不僅適用於 Cri/oFlex 3，亦可擴展至 Fraunhofer EMFT 的 < 100 μm 超薄超導纜線，以及未來 32 通道高密度量子互連產品。
