## 2. 各類傳輸線公式

### 2.1 同軸線 (Coaxial Line)

**結構參數：**
- $a$: 內導體半徑
- $b$: 外導體內徑
- $\epsilon_r$: 介質相對介電常數

**電容 (單位長度)：**
$$C = \frac{2\pi\epsilon}{\ln(b/a)} \quad [F/m]$$

**電感 (單位長度)：**
$$L = \frac{\mu}{2\pi}\ln(b/a) \quad [H/m]$$

**特性阻抗：**
$$Z_0 = \frac{1}{2\pi}\sqrt{\frac{\mu}{\epsilon}}\ln\frac{b}{a} = \frac{60}{\sqrt{\epsilon_r}}\ln\frac{b}{a} \quad [\Omega]$$

**衰減常數：**

導體損耗：$\alpha_c = \frac{R_s}{4\pi Z_0}(\frac{1}{a} + \frac{1}{b})$ [Np/m]
介質損耗：$\alpha_d = \frac{\pi f \sqrt{\epsilon_r} \tan\delta}{c}$ [Np/m]

其中 $R_s = \sqrt{\pi f \mu / \sigma}$ 為表面電阻

### 2.2 微帶線 (Microstrip)

**結構參數：**
- $w$: 導帶寬度
- $h$: 介質厚度
- $t$: 導帶厚度 (通常可忽略)

**有效介電常數 (Wheeler-Hammerstad)：**
$$\epsilon_{eff} = \frac{\epsilon_r + 1}{2} + \frac{\epsilon_r - 1}{2}(1 + \frac{12h}{w})^{-0.5}$$

**特性阻抗：**

窄帶 ($w/h \leq 1$):
$$Z_0 = \frac{60}{\sqrt{\epsilon_{eff}}}\ln(\frac{8h}{w} + \frac{w}{4h})$$

寬帶 ($w/h \geq 1$):
$$Z_0 = \frac{120\pi}{\sqrt{\epsilon_{eff}}[w/h + 1.393 + 0.667\ln(w/h + 1.444)]}$$

**頻率色散 (Kirschning-Jansen 模型)：**

$$\epsilon_{eff}(f) = \epsilon_r - \frac{\epsilon_r - \epsilon_{eff}(0)}{1 + M}$$

其中：
$$M = P_1 P_2 [(0.1844 + P_3 P_4) \cdot 10 f_{GHz}]^{1.5763}$$

$$P_1 = 0.27488 + (0.6315 + \frac{0.525}{(1+0.0157f)^{20}})\frac{w}{h} - 0.065683 e^{-8.7513w/h}$$

$$P_2 = 0.33622(1 - e^{-0.03442\epsilon_r})$$

$$P_3 = 0.0363 e^{-4.6w/h} [1 - e^{-(w/h/0.038)^{1.4}}]$$

$$P_4 = 1 + 2.751(1 - e^{-(\epsilon_r/15.916)^8})$$

### 2.3 帶狀線 (Stripline)

**結構參數：**
- $w$: 導帶寬度
- $b$: 上下接地平面間距
- $t$: 導帶厚度

**特性阻抗 (寬帶近似 $w/b > 0.35$)：**
$$Z_0 = \frac{30\pi}{\sqrt{\epsilon_r}} \frac{b}{w_{eff} + 0.441b}$$

**有效寬度 (考慮厚度效應)：**
$$w_{eff} = w - \Delta w = w - \frac{t}{\pi}\ln\frac{4e}{\sqrt{(t/b)^2 + (\frac{t}{w\pi})^2}}$$

**優點：**
- 純TEM模式 (無色散)
- 比微帶線更好的隔離度
- 對稱的場分佈

### 2.4 共面波導 (CPW - Coplanar Waveguide)

**結構參數：**
- $w$: 中心導帶寬度
- $s$: 間隙寬度
- $h$: 介質厚度

**幾何比：**
$$k = \frac{w}{w + 2s}$$

**特性阻抗：**
$$Z_0 = \frac{30\pi}{\sqrt{\epsilon_{eff}}} \frac{K(k')}{K(k)}$$

其中 $k' = \sqrt{1-k^2}$，$K(k)$ 為第一類完全橢圓積分：

$$K(k) = \int_0^{\pi/2} \frac{d\theta}{\sqrt{1 - k^2\sin^2\theta}}$$

**有效介電常數：**
$$\epsilon_{eff} = 1 + q(\epsilon_r - 1)$$

其中 $q$ 為填充因子：
$$q = \frac{K(k)K(k_1')}{K(k')K(k_1)}$$

$$k_1 = \frac{\sinh(\pi w/4h)}{\sinh(\pi(w+2s)/4h)}$$

### 2.5 矩形波導 (Rectangular Waveguide)

**注意：** 波導傳輸的是TE或TM模式，不是TEM模式。

**結構參數：**
- $a$: 寬邊
- $b$: 窄邊 ($a > b$)

**TE₁₀模式截止頻率：**
$$f_c = \frac{c}{2a\sqrt{\epsilon_r}}$$

**導波波長：**
$$\lambda_g = \frac{\lambda_0}{\sqrt{1 - (f_c/f)^2}}$$

**相位常數：**
$$\beta = \frac{2\pi}{\lambda_0}\sqrt{1 - (f_c/f)^2}$$

**相速度：**
$$v_p = \frac{c}{\sqrt{\epsilon_r}\sqrt{1 - (f_c/f)^2}}$$

**群速度：**
$$v_g = \frac{c}{\sqrt{\epsilon_r}}\sqrt{1 - (f_c/f)^2}$$

**特性阻抗 (TE₁₀)：**
$$Z_{TE} = \frac{\eta}{\sqrt{1 - (f_c/f)^2}} = \frac{377}{\sqrt{\epsilon_r}\sqrt{1 - (f_c/f)^2}}$$

## 3. 串擾 (Crosstalk) 理論

### 3.1 耦合機制

串擾由兩種耦合機制引起：
1. **電容耦合 (容性串擾)**：通過互電容 $C_m$
2. **電感耦合 (感性串擾)**：通過互電感 $L_m$

### 3.2 耦合係數

**電容耦合係數：**
$$K_c = \frac{C_m}{C}$$

**電感耦合係數：**
$$K_L = \frac{L_m}{L}$$

對於微帶線的近似：
$$C_m \approx \frac{\epsilon_0(1+\epsilon_r)}{2} \frac{w}{s} e^{-s/h}$$

$$L_m \approx \frac{\mu_0}{2\pi}\ln(1 + (h/s)^2)$$

### 3.3 串擾計算

**近端串擾 (NEXT - Near-End Crosstalk)：**
$$NEXT = 20\log_{10}(\frac{K_c + K_L}{4}) \quad [dB]$$

**遠端串擾 (FEXT - Far-End Crosstalk)：**
$$FEXT = 20\log_{10}(\frac{(K_c - K_L)lf}{2v_p}) \quad [dB]$$

其中：

- $l$: 耦合長度
- $f$: 頻率
- $v_p$: 相速度

### 3.4 其他重要參數

**插入損耗 (IL - Insertion Loss)：**
$$IL = -20\log_{10}|S_{21}| = 8.686 \alpha l \quad [dB]$$

**回波損耗 (RL - Return Loss)：**
$$RL = -20\log_{10}|\Gamma| = -20\log_{10}|\frac{Z_L - Z_0}{Z_L + Z_0}| \quad [dB]$$

**駐波比 (SWR - Standing Wave Ratio)：**
$$SWR = \frac{1 + |\Gamma|}{1 - |\Gamma|}$$

## 6. 設計指南

### 6.1 50Ω微帶線設計 (FR-4, er=4.3, h=1.6mm)

目標：$Z_0 = 50\Omega$

使用近似公式：
$$\frac{w}{h} \approx \frac{8}{e^{Z_0\sqrt{\epsilon_{eff}}/60}} - \frac{0.25}{e^{Z_0\sqrt{\epsilon_{eff}}/60}}$$

迭代計算得：$w \approx 3.0$ mm

### 6.2 串擾最小化策略

1. **增加線間距**：串擾隨間距指數衰減
2. **減小耦合長度**：FEXT與長度成正比
3. **使用帶狀線**：比微帶線有更好的隔離
4. **添加接地屏蔽**：在信號線間添加接地過孔

### 6.3 頻率選擇

- **DC-1 GHz**: 同軸線、微帶線
- **1-10 GHz**: 微帶線、帶狀線、CPW
- **10-100 GHz**: CPW、波導、薄膜傳輸線
