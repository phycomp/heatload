## 七、關鍵公式與關係

```
              Ic 相關重要關係式
═══════════════════════════════════════════════════════════════════════════════

  1. 拆對電流 (Depairing Current) - 理論上限
     ┌───────────────────────────────────────────────────┐
     │  Id = (Hc × ξ) / (√2 × μ₀ × λ)                    │
     │                                                   │
     │  其中: Hc = 臨界磁場                              │
     │        ξ  = 相干長度 (Coherence Length)           │
     │        λ  = 穿透深度 (Penetration Depth)          │
     └───────────────────────────────────────────────────┘

  2. 臨界電流密度 (Jc) 經驗關係
     ┌───────────────────────────────────────────────────┐
     │  Jc(T,B) = Jc(0,0) × (1 - T/Tc)^n × (1 - B/Bc2)^m │
     │                                                   │
     │  其中: n ≈ 1.5-2.0 (溫度指數)                     │
     │        m ≈ 0.5-1.0 (磁場指數)                     │
     └───────────────────────────────────────────────────┘

  3. 釘扎力密度 (Pinning Force Density)
     ┌──────────────────────────────────────────────────┐
     │  Fp = Jc × B                                     │
     │                                                  │
     │  最大釘扎力發生在 B/Bc2 ≈ 0.2-0.3 處             │
     └──────────────────────────────────────────────────┘

  4. 自場效應 (Self-Field Effect)
     ┌───────────────────────────────────────────────────┐
     │  Bself = μ₀ × Jc × d / 2                          │
     │                                                   │
     │  其中: d = 超導層厚度                             │
     │  厚度增加 → 自場增加 → Jc 飽和                    │
     └───────────────────────────────────────────────────┘
```

這個文字示意圖完整呈現了影響超導體臨界電流的物理因素，從材料本質、微觀結構到外部條件，並特別針對CF3傳輸線的應用場景進行了優化策略說明。
