我來計算傳輸線總寬度設為 17mm、間距為 2mm 時的邊緣距離，並評估是否符合 CF3 設計規則。

| 參數 | 符號 | 數值 |
|------|------|------|
| 總寬度 | W_total | 17.0 mm |
| 通道數 | N | 8 |
| 通道間距 (Pitch) | P | 2.0 mm |
| 訊號線寬度 | w | 0.035 mm |
| 介電層厚度 | H | 0.129 mm |


## 步驟 1：計算 8 條訊號線的總寬度（不含邊緣）

```
訊號線總寬 = (N - 1) × P + w
           = 7 × 2.0 + 0.035
           = 14.035 mm
```


## 步驟 2：計算邊緣間距總和與單側間距

```
總邊緣空間 = W_total - 訊號線總寬
           = 17.0 - 14.035
           = 2.965 mm

單側邊緣間距 = 總邊緣空間 / 2
             = 2.965 / 2
             = 1.4825 mm
```


## 步驟 3：邊緣間距精確計算（含單位換算）

| 項目 | 數值 |
|------|------|
| 單側邊緣間距 | **1.4825 mm** |
| 單側邊緣間距 | **1482.5 μm** |


## 步驟 4：驗算總寬度

```
總寬 = 7 × 2.0 + 0.035 + 2 × 1.4825
     = 14.0 + 0.035 + 2.965
     = 17.0 mm ✅
```


## 步驟 5：評估是否符合設計規則

### 5.1 10H 規則（邊緣 Clearance）

```
10H = 10 × 0.129 = 1.29 mm
```

你的邊緣間距：**1.4825 mm** ≥ 1.29 mm ✅ **符合 10H 規則**

### 5.2 5W 規則（通道間串擾）

```
5W = 5 × 0.035 = 0.175 mm
通道間間距 = P - w = 2.0 - 0.035 = 1.965 mm
```

**1.965 mm** ≥ 0.175 mm ✅ **符合 5W 規則**
