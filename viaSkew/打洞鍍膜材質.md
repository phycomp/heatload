## 📐 TEM 模式電磁特性

### TEM (Transverse ElectroMagnetic) 模式定義

> **TEM 模式** 是電磁波傳播的一種模式，其中電場 $\vec{E}$ 和磁場 $\vec{H}$ 完全垂直於傳播方向，即縱向分量 $E_z = H_z = 0$
> [^web_search:12#1^][^web_search:12#8^]。

**Stripline 支援純 TEM 模式**，因為其介電填充為均勻的 Polyimide，無空氣-介電界面 [^web_search:12#1^]。

### TEM 模式核心公式

| 參數 | 公式 | 說明 |
|--|------|------|
| **場結構** | $\vec{E} = E_x \hat{x} + E_y \hat{y}$, $\vec{H} = H_x \hat{x} + H_y \hat{y}$ | 無縱向分量 |
| **相速度** | $v_p = \frac{c}{\sqrt{\varepsilon_r}}$ | 與頻率無關 (非色散) |
| **特性阻抗** | $Z_0 = \sqrt{\frac{L'}{C'}} \approx \frac{94.15}{\sqrt{\varepsilon_r}} \cdot \frac{1}{\frac{w_{eff}}{h} + 0.441}$ | 常數 |
| **導體損耗** | $\alpha_c \approx 0$ (超導態) | $R_s \to 0$ at $T \ll T_c$ |
| **介電損耗** | $\alpha_d = \frac{\pi f}{c}\sqrt{\varepsilon_r} \tan\delta$ | 主要損耗來源 |
| **品質因數** | $Q_c = \frac{\omega L}{R_s} \to \infty$ (超導) | 極高 Q 值 |

### Via TEM 等效電路 (同軸近似)

```
        L_via
    ┌────/\/\/\────┐
    │              │
   ─┤              ├─
    │      │       │
    │     === C    │
    │      │       │
    │      │       │
   ─┤              ├─
    │              │
    └──────────────┘
```

| 參數 | 公式 | Cri/oFlex 3 數值 |
|---|:--:|---|
| **Via 特性阻抗** | $Z_{0,via} = \frac{60}{\sqrt{\varepsilon_r}} \ln\left(\frac{b}{a}\right)$ | **~85 Ω** |
| **Via 電感** | $L_{via} \approx \frac{\mu_0}{2\pi} L \ln\left(\frac{b}{a}\right)$ | **~0.1 nH** |
| **Via 電容** | $C_{via} \approx \frac{2\pi\varepsilon_0\varepsilon_r L}{\ln(b/a)}$ | **~15 fF** |
| **電長度** | $\theta = \frac{2\pi L}{\lambda_g}$ | **< 1° @ 6 GHz** |

其中：

- $a$ = Via 半徑 = 75 μm
- $b$ = 接地層距離 = 575 μm
- $L$ = Via 深度 = 151 μm

## 🎯 設計建議 1. Via Coating 最佳選擇

**首選：NbTi (300 nm) + Ti Buffer (20 nm)**

- ✅ 與 Cri/oFlex 3 導體材料一致
- ✅ $T_c$ = 9.2 K，適合 4K 環境
- ✅ 低溫下零電阻，無微波損耗

**替代：TiN (CVD/ALD)**

- ✅ 高深寬比共形覆蓋優異 [^web_search:12#4^]
- ✅ 與 Polyimide 附著性極佳
- ⚠️ $T_c$ = 5 K，需確認操作溫度

| 優化方向 | 方法 | 效果 |
