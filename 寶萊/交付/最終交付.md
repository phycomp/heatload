## 技術規格

- **Microstrip**: Hammerstad-Jensen 公式，含厚度修正與頻率色散
- **Stripline**: Wheeler 精確橢圓積分公式，全範圍連續
- **IL 計算**: 導體損耗 (Hammerstad / Huray) + 介電損耗 (頻率相依 Df)
- **RL 計算**: 基於阻抗不匹配反射係數
- **疊構模板**: Rigid (4/6/8/10L) / RF Core Build / Flex-Rigid / HDI
- **材料庫**: FR-4 / Rogers / Megtron 6 / Teflon，可自訂擴充
