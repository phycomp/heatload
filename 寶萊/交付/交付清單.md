# 生成 README.md
readme = '''# PCB Transmission Line Calculator — Phase 1

Streamlit 應用：PCB 傳輸線阻抗計算、參數掃描與專案管理。

## 功能 (Phase 1)

| 模組 | 功能 |
|------|------|
| **📐 阻抗計算器** | Microstrip / Stripline 正向計算 (幾何→Z₀) 與反向計算 (目標Z₀→線寬) |
| **📊 參數掃描** | 單一參數掃描 (線寬/介質厚度/銅厚/Dk) → Z₀ 與 εeff 曲線 |
| **💾 專案檔案** | JSON 儲存/載入計算參數 |

## 技術規格

- **Microstrip**: Hammerstad-Jensen 經典公式，含厚度修正與頻率色散 (Dispersion)
- **Stripline**: IPC-2141 / Wheeler 對稱帶狀線公式
- **反向求解**: `scipy.optimize.brentq` 數值反解
- **繪圖**: Plotly 互動式圖表
- **材料庫**: 7 種預設材料 (FR-4, Rogers, Megtron 6 等)，可自訂擴充

## 安裝與執行

```bash
# 1. 安裝依賴
pip install -r requirements.txt

# 2. 啟動 Streamlit
streamlit run app.py
```

## 專案結構

```
pcb_calc_app/
├── app.py                      # Streamlit 主入口
├── requirements.txt
├── data/
│   └── materials.json          # 預設材料庫
├── modules/
│   └── impedance/
│       ├── formulas.py         # Microstrip / Stripline 公式
│       ├── solver.py           # 正向/反向求解器
│       └── sweep.py            # 參數掃描引擎
├── utils/
│   └── project_io.py           # JSON 專案檔讀寫
└── saved_projects/             # 使用者儲存的專案檔
```

## Phase 2 預告

- 補齊所有傳輸線類型 (CPW, Edge-coupled, Broadside-coupled, Coaxial...)
- 精確模型切換 (經典 vs 進階)
- 雙參數 2D 熱力圖掃描
- 蒙特卡羅製程公差分析
'''

with open(f"{base}/README.md", "w", encoding="utf-8") as f:
    f.write(readme)
